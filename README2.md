# 6Gang 项目计划（二） — KOL 数字孪生

> 基于 B 站 UP 主公开内容，构建个体级数字孪生 · MUR × 北大元培

---

## 项目到底要做什么

**KOL 数字孪生**：基于 B 站硬核测评 UP 主的视频内容，构建「像真人一样思考和表达」的 AI 分身。

与群体画像的关键区别：


|      | 群体画像            | KOL 分身          |
| ---- | --------------- | --------------- |
| 粒度   | 聚类画像（5-8 种类型）   | 个体孪生（每人独立）      |
| 数据源  | 访谈笔录（docx/xlsx） | B站公开视频内容        |
| 核心目标 | 用研人员选标签匹配画像对话   | 像跟真人 UP 主深访一样提问 |
| 评价标准 | 画像一致性           | 人设还原度 + 专业判断准确性 |

## 各职能任务



### AI 开发 × 3（崔续衡 闫瑾 林钰坤）

- [x] **任务 1：数据采集与清洗** — 70 个视频的音频下载、whisper-medium GPU 转写、DeepSeek 标点恢复、B站话术清洗。产物：`data/kol/{name}_all.json`。

- [x] **任务 2：KOL 画像提取** — 从 17 万字语料中，用 LLM 自动提取 personaCard（身份/评价体系/内容领域）和 styleProfile（口头禅/语气/句式特征）。产物：`apps/api/src/db/seed-kol.ts` 中的 `extractWithLLM()`。

- [x] **任务 3：LLM SDK 封装** — 复用群体画像的 `apps/api/src/lib/llm.ts`，支持 DeepSeek/GLM/MiniMax 切换。

- [ ] **任务 4：Embedding 生成** — 对 389 条 kol_segments 调 `embed()` 生成向量，写入 `embedding` 列。产物：`scripts/embed-kol.ts`。

- [ ] **任务 5：RAG 向量搜索** — 将 `kol.ts` 对话中的 ILIKE 模糊匹配替换为 pgvector 余弦相似搜索。需要先完成任务 4。实现方式：`ORDER BY embedding <=> query_vector LIMIT 5`。

- [ ] **任务 6：Prompt 工程优化** — 当前 System Prompt 模板在 `kol.ts` 中硬编码，基于 LLM 提取的画像字段组装。需要系统验证：画像字段是否完整？口头禅是否过于刻意？回答是否能体现 UP 主的评价体系而非泛泛而谈？产物：Prompt 版本记录 + A/B 测试日志。

- [ ] **任务 7：自动化评测脚本** — 将 KOL 测试题集从 xlsx 转为结构化 JSON，写评测脚本遍历用例 → 调 `/api/kol/chat` → 保存回答 → 人工评分或 LLM-as-judge 打分。重点验证：人设一致性（语气像本人吗）、专业准确性（评价逻辑对吗）、知识边界（不懂的会说不知道吗）。产物：评测脚本 + 评测报告。

### 交互设计 × 1（闫瑾）

- [ ] **任务 1：KOL 列表页设计** — UP 主卡片展示：头像（可从B站拉取）、简介、视频数、口头禅预览。与群体画像列表做差异化——这里是「人」不是「类型」。

- [ ] **任务 2：KOL 对话室设计** — 对话气泡样式、UP 主信息卡（身份 + 口头禅 + 往期话题）、溯源入口（点击查看来源视频）、流式打字动效。产物：Figma 高保真稿。

- [ ] **任务 3：KOL 对比功能设计** — 同一问题同时问两位 UP 主，对比他们的不同观点。这是 KOL 分身独有的产品价值。产物：交互稿。

### 测试 × 2（张江宇 林钰坤）

- [ ] **任务 1：测试策略与题库整理** — 将 KOL 测试题集 4 个 Sheet（一致性测试、立项判断、推广合作、设计反馈）按维度分类编号。产物：测试策略文档。

- [ ] **任务 2：人设一致性评测** — 验证 AI 是否正确还原了 KOL 的个人特征：语气和口头禅是否自然、游戏审美标准是否自洽、评价体系是否前后一致。产物：一致性评测报告。

- [ ] **任务 3：专业性评测** — 用假设性题目（立项/合作/设计反馈三类）验证 AI 回答是否体现 UP 主的专业水准：能否给出有洞察的判断、能否从"内容创作者+硬核玩家"双重视角出发。产物：专业性评测报告。

- [ ] **任务 4：盲测** — 选 10 道代表性题，AI 回答 vs UP 主真实视频回答混合，评委盲评。目标区分准确率 ≤ 50%。产物：盲测报告。

### 用研专家 × 2（类恺平 朱丽烨）

- [ ] **任务 1：KOL 画像校验** — 审核 LLM 自动提取的 personaCard 和 styleProfile 是否准确。口头禅真的能代表这个 UP 主吗？评价体系权重对吗？产物：画像校验报告。

- [ ] **任务 2：对话质量审核** — 和两位 KOL 分身各进行 10 轮以上深度对话（模拟游戏开发者立项咨询场景），逐条记录：哪里像真人、哪里崩了、哪里泛泛而谈。产物：对话质量审核报告。

- [ ] **任务 3：评测标准制定** — 定义"像这个 UP 主"的量化标准：语气一致性、审美自洽性、表达能力、知识边界诚实度。产物：KOL 评测标准文档。

- [ ] **任务 4：盲测材料准备** — 从 KOL 真实视频中截取对应问题的回答，供盲测使用。产物：盲测对照材料。

## 评测标准

- 人设一致性通过率 ≥ 80%（语气、口头禅、评价逻辑不崩）
- 专业性平均评分 ≥ 3.5/5（回答体现 UP 主的专业判断力）
- 盲测评委区分准确率 ≤ 50%（AI 与真人难以区分）
- 多轮对话 ≥ 15 轮不崩人设
