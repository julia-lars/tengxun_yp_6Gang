## KOL 分身要做什么

**目标**：基于两位 B 站硬核测评 UP 主的所有公开内容，构建可 1v1 深度对话的 AI 数字孪生。

```
用户选择 KOL 分身 → 进入 1v1 对话界面 → 提问（立项判断/推广合作/设计反馈）
                                 → AI 以该 KOL 的风格、审美、评价体系回答
                                 → 可溯源到该 KOL 的真实视频/言论
```

**与群体画像的核心区别**：

| 维度 | 群体画像 | KOL 分身 |
|------|----------|----------|
| 粒度 | 群体级（一类人） | 个体级（一个人） |
| 数据源 | 70+ 篇用研访谈笔录 | B 站公开内容（视频/动态/评论） |
| 核心约束 | 像"这类玩家" | 像"这个人本人" |
| 风格要求 | 语言风格一致即可 | 口头禅、句式、语气节奏高度还原 |
| 评价体系 | 冰山模型五层 | 冰山模型 + 个人审美偏好 + 商业态度 |
| 数据量 | 每画像数百条片段 | 每人全量公开内容 |

### 风格特征提取（AI 开发）

- [x] **任务 4：口头禅与高频表达提取** — 已从清洗后语料中提取标志性表达。
  - 鬼王陆行：`鬼王我` / `说实话` / `我只能说` / `必须得说`
  - 冷面叶星星IKGN：`1000小时` / `11分` / `叶指导` / `冷面姐`
  - 🔧 **优化**：当前为人工挑选，未做 N-gram 统计分析。建议用 LLM 对全量语料自动提取跨视频高频口头禅，并标注使用场景

    2. 缺句式结构偏好分析（长从句 vs 短句、排比 vs 散句、感叹号率）

- [x] **任务 7：KOL Persona Card 构建** — 已在 `seed-kol.ts` 中整合输出到 `kol_profiles.persona_card` 和 `style_profile` 字段。

## 评测标准

- 一致性测试通过率 ≥ 70%（同 KOL 不矛盾，两个 KOL 可明确区分）
- 假设性测试平均评分 ≥ 3/5（回答符合该 KOL 的人设和评价体系）
- 盲测评委区分准确率 ≤ 50%（AI 与该 KOL 本人言论难以区分）
- 口头禅/风格还原度 ≥ 4/5（由该 KOL 的粉丝或熟悉其内容的评委主观评分）
