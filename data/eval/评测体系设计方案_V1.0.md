## 一、评价目标

当前评价对象不是单纯的「AI 回答质量」，而是整个 Pipeline：

> **访谈语料 → M1–M5 打标 → 向量化 → 聚类 → 玩家画像 → RAG → 模拟用户**

最终回答四个核心问题：

1. **AI 有没有发现真实存在的玩家群体？**（聚类是否反映了数据中客观存在的结构）
2. **不同玩家群体之间有没有真实、稳定、可解释的差异？**（画像之间是否真正可区分）
3. **生成的画像是否真实来自原始访谈，而不是 LLM 自己编造？**（画像的每个核心命题是否有证据支撑）
4. **AI 模拟出来的玩家是否真的表现出了这个群体的行为、动机和需求？**（模拟回答是否忠实于真实玩家群体）

因此最终评价不是单一指标，而是：

> **Cluster Validity + Persona Validity + Simulation Fidelity + Reliability**

---

## 二、总评分结构

| 一级维度 | 权重 | 核心问题 |
| --- | ---: | --- |
| **A. 聚类真实性 Cluster Validity** | **40%** | 聚类结构是否真实、稳定、可解释 |
| **B. 画像真实性 Persona Validity** | **25%** | 画像文本是否忠实于原始数据 |
| **C. 模拟忠实度 Simulation Fidelity** | **25%** | AI 模拟回答是否体现群体特征 |
| **D. 评价可靠性 Reliability** | **10%** | 评分体系本身是否可信 |
| **总分** | **100%** | — |

### 核心规则：D 层是质量门槛，不是加分项

即使 A=90、B=88、C=91，如果 Reliability 未达到要求，整个评价结果不能被判定为有效。D 层不通过 → 总分无效，需修复评分体系后再评。

## 三、A 层：聚类真实性（40 分）

这是整个评价体系最重要的一层，回答「聚类结构是否真实」。

### A1. 类内一致性（10 分）

**核心问题**：同一个 cluster 中的玩家是不是真的相似？

从五个层面分别计算，对应冰山模型 M1–M5：

| 子维度 | 分值 | 说明 |
| --- | ---: | --- |
| M5 行为一致性 | 2 | 同一 cluster 内玩家的外显行为模式是否相似 |
| M4 感受一致性 | 2 | 同一 cluster 内玩家的情绪/感受模式是否相似 |
| M3 认知一致性 | 2 | 同一 cluster 内玩家的认知/观点模式是否相似 |
| M2 期待一致性 | 2 | 同一 cluster 内玩家的期待/标准是否相似 |
| M1 动机一致性 | 2 | 同一 cluster 内玩家的深层动机是否相似 |

**量化方式**：

对每个 cluster，计算：

```text
类内平均相似度 / 全体随机玩家对平均相似度
```

相似度应融合三个信号源：

1. **Embedding cosine similarity** — 语义向量相似度
2. **M1–M5 semantic similarity** — 基于标签分布的语义相似度
3. **玩家行为特征相似度** — 基于结构化标签（能力、风格、平台、模式等）的 Gower 距离

最终归一化到 0–100，再映射到 10 分制。

**评分标准**：

| 得分 | 标准 |
| ---: | --- |
| 9–10 | 五层均 ≥ 85，类内高度凝聚 |
| 7–8 | 大部分 ≥ 75，个别层略低 |
| 5–6 | 部分层 ≥ 65，存在明显弱层 |
| 3–4 | 多数层 < 65，类内松散 |
| 1–2 | 类内几乎无凝聚 |

---

### A2. 类间区分度（10 分）

**核心问题**：C1 和 C2 到底是不是不同的玩家群？这是现有体系需要明显加强的部分。

对每一对 cluster（C1×C2, C1×C3, C2×C3…），计算多维度的类间分离度：

| 维度 | 度量方式 |
| --- | --- |
| M1 差异 | 动机标签分布 KL 散度 |
| M2 差异 | 期待标签分布 KL 散度 |
| M3 差异 | 认知标签分布 KL 散度 |
| M4 差异 | 感受标签分布 KL 散度 |
| M5 差异 | 行为标签分布 KL 散度 |
| Embedding distance | 簇质心余弦距离 |
| 外部属性差异 | 能力等级、平台、模式等结构化标签的分布差异 |

最终形成 **Cluster Distinctiveness Matrix**：

|  | C1 | C2 | C3 | C4 | C5 |
| --- | ---: | ---: | ---: | ---: | ---: |
| C1 | — | 82 | 91 | 57 | 78 |
| C2 | 82 | — | 76 | 43 | 85 |
| C3 | 91 | 76 | — | 71 | 63 |
| C4 | 57 | 43 | 71 | — | 52 |
| C5 | 78 | 85 | 63 | 52 | — |

> 值越高 = 区分越清晰。C2/C4 = 43 → 高度重叠，需重点关注。

**评分标准**：

| 得分 | 标准 |
| ---: | --- |
| 9–10 | 所有 pair 均 ≥ 70，无重叠簇 |
| 7–8 | 绝大多数 pair ≥ 70，个别 pair 60–70 |
| 5–6 | 存在 1–2 个 pair < 60，需合并或重分 |
| 3–4 | 多个 pair < 50，聚类结构不清晰 |
| 1–2 | 大量重叠，簇之间几乎无区分 |

---

### A3. 聚类稳定性（8 分）

**核心问题**：换一批样本，是否还能得到相同的群体结构？

**方法：Bootstrap / Resampling**

1. 从原始数据中随机抽取 80% 样本
2. 重复 30–50 次
3. 每次重新执行完整流程：Embedding → HDBSCAN → Cluster
4. 比较每次聚类结果的一致性

**度量指标**：

| 指标 | 说明 |
| --- | --- |
| ARI（Adjusted Rand Index） | 校正后的 Rand 指数，消除随机一致性 |
| NMI（Normalized Mutual Information） | 归一化互信息 |
| Jaccard 相似度 | 簇成员重叠比例 |

> 注意：cluster label 本身没有固定编号，需先做 cluster matching（匈牙利算法匹配最优标签对应）。

**评分标准**：

| 得分 | ARI | 解读 |
| ---: | ---: | --- |
| 7–8 | ≥ 0.85 | 高度稳定，换样本基本得到相同结构 |
| 5–6 | 0.70–0.85 | 基本稳定，个别簇边界波动 |
| 3–4 | 0.50–0.70 | 中等稳定，部分簇不稳定 |
| 1–2 | < 0.50 | 不稳定，聚类结构对样本敏感 |

---

### A4. 玩家级一致性（7 分）

**核心问题**：同一个玩家的不同语料片段，是否被分到了同一个 cluster？

因为一个受访者（speaker_id）会产生多条语料片段，必须避免「AI 把同一个人的不同表达当成不同画像」。

**计算方式**：

以 `speaker_id`（Player ID）为 Group，计算每个玩家的语料片段中，进入其主 cluster 的比例：

| 玩家 | 总片段数 | 主 Cluster | 主 Cluster 占比 |
| --- | ---: | --- | ---: |
| P01 | 12 | C3 | 87% |
| P02 | 8 | C1 | 91% |
| P03 | 15 | C2 | 74% |
| P04 | 10 | C4 | 86% |

然后计算总体 **Player Cluster Consistency（PCC）**：

```text
PCC = 所有玩家在其主 cluster 中的片段数之和 / 所有玩家总片段数
```

**反作弊规则**：

- 不能「每个玩家一个 cluster」——同时要求 cluster 数量合理、cluster size 不极端、多玩家覆盖。
- 若某 cluster 中 ≥ 70% 数据来自同一个玩家 → 触发 **Player Dominance Warning**，该 cluster 降级为「单人特征」而非「群体画像」。

**评分标准**：

| 得分 | PCC | 解读 |
| ---: | ---: | --- |
| 6–7 | ≥ 85% | 同一玩家高度聚合 |
| 4–5 | 70–85% | 基本聚合，但存在跨簇碎片 |
| 2–3 | 50–70% | 同一玩家被严重分散 |
| 1 | < 50% | 聚类几乎不反映玩家一致性 |

---

### A5. 聚类可解释性（5 分）

**核心问题**：每个 cluster 为什么是一类人？能不能用冰山模型解释清楚？

每个 cluster 必须能回答：

| 层 | 要求 |
| --- | --- |
| M5 | 这个群体有什么共同的行为模式？ |
| M4 | 这个群体有什么共同的感受/情绪模式？ |
| M3 | 这个群体有什么共同的认知/观点？ |
| M2 | 这个群体有什么共同的期待/标准？ |
| M1 | 这个群体有什么共同的深层动机？ |

每个核心结论必须有 **≥ 3 条原始访谈证据** 支撑，且证据来源 ≥ 3 个不同的受访者。

**评分标准**：

| 得分 | 标准 |
| ---: | --- |
| 5 | 所有 cluster 的 M1–M5 均有充分证据，且证据链清晰可追溯 |
| 4 | 大部分 cluster 解释充分，个别层证据偏弱 |
| 3 | 部分 cluster 解释偏泛，「为什么是一类人」不清晰 |
| 2 | 多数 cluster 只能给出笼统描述，缺乏具体证据 |
| 1 | 画像主要是 LLM 生成的自然语言，无法追溯到原始访谈 |

---

### A 层汇总

```text
A = A1(10) + A2(10) + A3(8) + A4(7) + A5(5) = 40
```

## 四、B 层：画像真实性（25 分）

这一层解决「Cluster 是真的，但 AI 写出来的画像有没有胡说」。

### B1. Evidence Coverage（8 分）

**核心问题**：画像中的每个核心命题，是否能追溯到原始访谈？

**计算方式**：

每个画像应包含 **10–20 个核心命题**（而非一大段自然语言描述），每个命题必须是可验证的断言。

```text
Evidence Coverage = 有直接访谈证据支持的核心命题数 / 全部核心命题数
```

**证据要求**：

- 每个命题至少 2 条来自不同受访者的访谈原文支撑
- 证据引用必须包含 `speaker_id` 和片段原文（可追溯）

**评分标准**：

| 得分 | Evidence Coverage | 解读 |
| ---: | ---: | --- |
| 7–8 | ≥ 90% | 几乎所有命题有充分证据 |
| 5–6 | 75–90% | 大部分有证据，少量推测 |
| 3–4 | 50–75% | 近半命题缺乏证据支撑 |
| 1–2 | < 50% | 画像主要是 LLM 推断，缺乏数据基础 |

---

### B2. Evidence Consistency（7 分）

**核心问题**：有证据还不够，cluster 中有多少比例的玩家真正支持这个命题？

**计算方式**：

对画像的每个核心命题，计算该 cluster 中支持该命题的玩家比例：

```text
Support Rate = 支持该命题的玩家数 / cluster 内总玩家数
```

然后取所有命题的 Support Rate 均值：

```text
Evidence Consistency = mean(所有核心命题的 Support Rate)
```

**区分**：

- 10 个玩家中 9 个支持 → 高一致性，是真正的群体特征
- 10 个玩家中 2 个支持 → 低一致性，更像是少数人的特征被放大为代表

**评分标准**：

| 得分 | 平均 Support Rate | 解读 |
| ---: | ---: | --- |
| 6–7 | ≥ 80% | 群体特征高度一致 |
| 4–5 | 60–80% | 基本一致，存在内部差异 |
| 2–3 | 40–60% | 群体内部差异大，画像可能过度概括 |
| 1 | < 40% | 画像命题与群体实际情况严重不符 |

---

### B3. Contradiction Rate（5 分）

**核心问题**：主动寻找反证——画像说「该群体反感付费」，但有多少玩家实际表示愿意付费？

**计算方式**：

对画像的每个核心命题，检查 cluster 内是否存在与之矛盾的玩家证据：

```text
Contradiction Rate = 存在反证的核心命题数 / 全部核心命题数
```

**为什么重要**：LLM 很容易选择性引用支持自己的证据，忽略反例。Contradiction Rate 是防止「确认偏误」的关键指标。

**评分标准**：

| 得分 | Contradiction Rate | 解读 |
| ---: | ---: | --- |
| 5 | ≤ 10% | 几乎无内部矛盾，画像高度准确 |
| 4 | 10–20% | 少量内部矛盾，画像基本准确 |
| 3 | 20–35% | 存在明显内部矛盾，部分命题需修正 |
| 2 | 35–50% | 严重内部矛盾，画像可能失真 |
| 1 | > 50% | 画像与群体实际情况大面积冲突 |

---

### B4. Profile Distinctiveness（5 分）

**核心问题**：两个画像不能写成「都喜欢枪械、都重视体验、都希望平衡、都喜欢新内容」然后仅仅改几个形容词。

**计算方式**：

对每一对画像，比较其核心命题的语义重叠度：

1. 提取画像 A 和画像 B 的所有核心命题
2. 计算命题之间的语义相似度（embedding cosine similarity）
3. 统计相似度 > 0.8 的命题对比例

```text
Distinctiveness = 1 − (高相似度命题对数量 / 全部命题对数量)
```

**评分标准**：

| 得分 | Distinctiveness | 解读 |
| ---: | ---: | --- |
| 5 | ≥ 85% | 各画像核心命题高度差异化 |
| 4 | 70–85% | 画像间有明显区分，存在少量通用描述 |
| 3 | 50–70% | 画像间存在较多重叠描述 |
| 2 | 30–50% | 画像间严重趋同 |
| 1 | < 30% | 画像几乎可以互换 |

---

### B 层汇总

```text
B = B1(8) + B2(7) + B3(5) + B4(5) = 25
```

## 五、C 层：模拟忠实度（25 分）

这一部分是现有 122 道测试题最适合发挥的地方。核心逻辑不再问「回答好不好」，而是问「回答是不是这个玩家群体会给出的回答」。

### C1. M5 行为忠实度（5 分）

**核心问题**：AI 模拟的行为选择是否符合真实玩家群体？

例如：「如果加入随机武器，你会怎么做？」——判断 AI 的行为选择（继续刚枪 / 苟着发育 / 直接退出）是否与真实群体一致。

**评分方式**：对行为类测试题，判断 AI 回答中的行为模式是否与 cluster 的 M5 标签一致。

---

### C2. M4 感受忠实度（4 分）

**核心问题**：AI 表达的情绪/感受是否符合真实玩家？

不是评价「这句话写得有没有感情」，而是判断「真实玩家是否表现出了这种感受」。

**评分方式**：对感受类测试题，判断 AI 回答中的情感倾向（兴奋/挫败/平淡/焦虑）是否与 cluster 的 M4 标签一致。

---

### C3. M3 认知忠实度（4 分）

**核心问题**：AI 是否复现了真实玩家的判断逻辑？

例如：玩家为什么认为这个设计公平/不公平？判断标准是什么？

**评分方式**：对认知类测试题，判断 AI 回答中的判断逻辑和归因方式是否与 cluster 的 M3 标签一致。

---

### C4. M2 期待忠实度（4 分）

**核心问题**：AI 的需求优先级是否与真实玩家一致？

例如：如果游戏增加某功能，AI 希望得到什么？优先级排序是否与真实群体一致？

**评分方式**：对期待类测试题，判断 AI 回答中的需求优先级排序是否与 cluster 的 M2 标签一致。

---

### C5. M1 动机忠实度（4 分）

**核心问题**：AI 有没有真正复现这个群体的深层驱动力？这是最重要、也最难的一层。

例如：「为什么你真正愿意长期玩这款游戏？」——判断 AI 的回答是否体现了正确的深层动机。

**特别说明**：M1 单独作为项目核心指标。如果 M5=90、M1=45，说明 AI 只学会了「玩家做什么」，没有学会「玩家为什么这么做」。

**评分方式**：对动机类测试题，判断 AI 回答中的核心驱动力是否与 cluster 的 M1 标签一致。

---

### C6. 群体区分度（4 分）

**核心问题**：同一道题，C1/C2/C3 都回答，回答之间有没有表现出真实的群体差异？

**计算方式**：

1. 同一道题向所有 cluster 分别发送
2. 收集所有 cluster 的回答
3. 计算回答之间的语义差异度（embedding distance / KL 散度）
4. 判断差异是否与 cluster 间的真实标签差异一致

**反例**：如果所有 cluster 都回答「我觉得挺有意思，主要看具体体验……」，那么即使每个答案单独都 4/5，Simulation Fidelity 仍然应该很低。

**评分标准**：

| 得分 | 标准 |
| ---: | --- |
| 4 | 各 cluster 回答有明显且符合预期的群体差异 |
| 3 | 大部分题目有区分度，个别题趋同 |
| 2 | 约半数题目各 cluster 回答趋同 |
| 1 | 几乎所有题目各 cluster 回答雷同 |

---

### C 层汇总

```text
C = C1(5) + C2(4) + C3(4) + C4(4) + C5(4) + C6(4) = 25
```

### C 层评分标准总表

| 得分 | 标准 |
| ---: | --- |
| 5 | AI 回答完全符合 cluster 在该层的标签特征，有具体的群体特异性 |
| 4 | 基本符合，存在少量偏差但不影响整体判断 |
| 3 | 部分符合，但存在明显偏差或泛化回答 |
| 2 | 大部分不符合，AI 回答与 cluster 特征脱节 |
| 1 | 完全不符合，AI 回答与 cluster 特征矛盾 |

## 六、D 层：评价可靠性（10 分）

这一层不是简单的「再加 10 分」，而是判断评分体系本身是否可信。

### D1. Test-Retest Reliability（3 分）

**方法**：同一 cluster + 同一题目，重复生成回答 3–5 次，使用 ICC（Intraclass Correlation Coefficient）评估一致性。

| ICC | 判断 |
| ---: | --- |
| ≥ 0.90 | 优秀 |
| 0.80–0.90 | 良好 |
| 0.70–0.80 | 可接受 |
| < 0.70 | 不稳定 |

**评分**：ICC ≥ 0.80 → 3 分；0.70–0.80 → 2 分；< 0.70 → 1 分。

---

### D2. Judge Agreement（3 分）

**方法**：多个 Judge（不同 LLM 或同一 LLM 不同 temperature）对同一答案评分，计算 ICC 或 Krippendorff's α。

**评分**：α ≥ 0.80 → 3 分；0.70–0.80 → 2 分；< 0.70 → 1 分。

---

### D3. Human Agreement（2 分）

**方法**：抽取 10–20% 的题目，由人工评分，比较 AI Judge vs Human 的一致性。

**评分**：AI-Human 相关系数 ≥ 0.80 → 2 分；0.65–0.80 → 1 分；< 0.65 → 0 分。

---

### D4. Prompt Robustness（2 分）

**方法**：同一答案，换用不同的 Judge Prompt（改变措辞但不改变评分维度），检查评分是否稳定。

**反例**：Prompt A=4.4、Prompt B=3.2、Prompt C=4.5 → Judge 不稳定。

**评分**：三次 Prompt 评分标准差 ≤ 0.3 → 2 分；0.3–0.6 → 1 分；> 0.6 → 0 分。

---

### D 层汇总

```text

```

### D 层门槛判定

| D 总分 | 判定 |
| ---: | --- |

| 6–7 | CONDITIONAL — 评价结果可参考但需标注局限性 |
| < 6 | FAIL — 评价结果不可信，需修复评分体系 |

## 八、统计显著性层

后续版本比较（V1 vs V2）时，不能简单说「81 → 84 = 提升 3 分」。

### 8.1 比较方法

采用 **paired bootstrap**：V1 和 V2 必须使用完全相同的问题、玩家、cluster、测试集。

### 8.2 报告指标

| 指标 | 说明 |
| --- | --- |
| Δ 分数 | 两个版本总分差值 |
| 95% CI | Bootstrap 95% 置信区间 |
| p 值 | 配对检验的显著性水平 |
| Cohen's d | 效应量（effect size） |

### 8.3 报告格式

```text
V2 vs V1
Δ = +3.2
95% CI = [+1.8, +4.6]
p < .01
Cohen's d = 0.43 (中等效应)
```

这样才能说「V2 的提升具有统计意义」，而不是「我们感觉 V2 好了一点」。

### 8.4 各维度独立比较

除总分外，还应对 A/B/C/D 各层及各子维度分别报告效应量和置信区间，以精确定位提升或退步的来源。

## 九、测试题重组织建议

### 9.1 现有结构

当前测试题分为两大类：

| 类型 | 题数 | 说明 |
| --- | ---: | --- |
| 一致性测试 | 31 | 验证 AI 回答是否内化群体特征 |
| 假设性测试 | 91 | 立项/玩法/商业化/市场营销 |

### 9.2 建议：增加 Question × M1–M5 矩阵

将每道题同时映射到 M1–M5 层，形成交叉矩阵：

| 题型 | M5 行为 | M4 感受 | M3 认知 | M2 期待 | M1 动机 | 合计 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| 一致性测试 | 8 | 7 | 8 | 6 | 6 | 35 |
| 玩法假设 | 12 | 8 | 10 | 13 | 8 | 51 |
| 立项 | 4 | 3 | 8 | 10 | 8 | 33 |
| 商业化 | 3 | 4 | 6 | 7 | 5 | 25 |
| 市场 | 5 | 3 | 6 | 8 | 5 | 27 |
| **合计** | **32** | **25** | **38** | **44** | **32** | **171** |

> 注：上表为示例，实际数值需根据现有 122 道题逐题打标后确定。一道题可能同时涉及多个 M 层，因此合计可能 > 122。

### 9.3 矩阵的价值

有了这个矩阵，最终可以发现：

> 不是「122 题平均 4.1 分」，而是「行为模拟很好（M5=91），动机模拟明显不足（M1=61）」。

这对项目方向的意义完全不同——前者只需要优化 Prompt，后者需要重新审视 M1 打标和画像生成逻辑。

## 十、附录：评价体系定义

> **6Gang 的 AI 聚类能力，不定义为「AI 能否生成看起来合理的玩家画像」，而定义为：AI 能否从真实访谈中稳定发现具有内部一致性、外部可验证性、群体区分性和证据支撑的玩家结构，并进一步忠实模拟这些群体在行为、感受、认知、期待和动机上的差异。**
