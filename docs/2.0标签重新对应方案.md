> 版本：v1.0
> 日期：2026-09-01
> 目的：定义从现有 Profile 六大维度 + Segment Annotation framework 标签 → 2.0 前台 5 维标签选择器 + 冰山心智链的完整映射关系
> 输入：《标签体系产品方案.md》v2.0、《用户画像Profile生成规范》v1.0、《数据标注规范》v3.1

### 0.2 映射策略

| 前台维度 | 主数据源 | 辅助数据源 | 映射方式 |
|---|---|---|---|
| 游戏诉求 | `motivations_needs.motivation` | `framework.needs` + `iceberg.M1` | 语义归类 → 12个值域标签 |
| 游戏能力 | `experience_capability.capability` | `framework.ability` + `motivations_needs` | 等级判定 + 技巧提取 |

| 冰山心智链 | `motivations_needs` + `perceptions_beliefs` + `behaviors` | `iceberg.M1-M5` (直接继承) | 5层证据聚合 |

## 1. 维度一：游戏诉求（多选，最多3个，标记首要）

### 1.1 映射来源

| 优先级 | 数据源 | 字段 | 说明 |
|---|---|---|---|
| P0 | `motivations_needs` | `trait_type=motivation` 的 `statement` | Profile层已聚合的动机描述 |
| P1 | `framework.needs` | `primary` / `secondary` | Segment级的诉求标签 |
| P2 | `iceberg.M1_motivation` | 各Segment的M1标签 | 冰山模型底层证据 |

### 1.2 映射规则：从 Profile statement → 12个值域标签

**核心逻辑：对 Profile 层的 motivation statement 做语义分类，映射到12个前台标签值。**

#### 映射表

| 前台标签值 | 产品显示名 | Profile statement 关键词/模式 | framework.needs 对应值 |
|---|---|---|---|
| `ability_growth` | 能力成长 | "提升技术""变强""练习""成长""进步""学习""钻研""弥补短板" | `ability_growth` |
| `competitive_proof` | 竞技证明 | "证明自己""段位""排名""比别人强""竞技""胜负""击败""碾压" | `competitive_proof` |

| `team_cooperation` | 团队协作 | "团队配合""协作""合作""配合取胜""集体""共同完成" | `team_cooperation` |
| `social_belonging` | 社交归属 | "朋友一起""社交""归属""圈子""开黑""关系""认识人""不孤单" | `social_belonging` |
| `stimulation` | 射击爽感 | "爽快""刺激""爽感""打击感""枪感""击杀反馈""爽""释放" | `stimulation` |
| `relaxation_escape` | 放松逃避 | "放松""解压""逃避""消磨时间""休闲""轻松""不累""压力" | `relaxation_escape` |
| `strategy_mastery` | 策略掌控 | "策略""战术""布局""分析""斗智""预判""资源""判断""掌控" | `strategy_mastery` |
| `exploration_collection` | 探索收集 | "探索""发现""收集""收藏""仓库""新鲜""好奇""尝试""经营" | `exploration_collection` |
| `narrative_immersion` | 叙事沉浸 | "剧情""世界观""角色""故事""沉浸""代入""氛围""临场""世界" | `narrative_immersion` |
| `sensory_aesthetics` | 视听审美 | "画面""画风""音效""动作""美术""好看""风格""视觉""特效" | `sensory_aesthetics` |
| `expression_creation` | 表达创造 | "自定义""建造""外观""UGC""创作""表达""个性""装扮""捏脸" | `expression_creation` |

#### 映射优先级规则

1. **如果有 `framework.needs.primary`**：直接映射（值域完全一致），confidence = 0.95
2. **如果有 `motivations_needs.motivation` 的 statement**：用语义匹配上述关键词，confidence = 0.85
3. **如果只有 `iceberg.M1_motivation`**：作为兜底，confidence = 0.75
4. **无证据**：标记为 `unknown`

#### 首要诉求判定

- `framework.needs.primary` 直接作为首要诉求
- 若无 framework 标注，取 Profile 层 confidence 最高的 motivation trait 对应的标签
- 若多个 motivation 的 confidence 相当，取 `motivations_needs` 中第一个出现的

## 2. 维度二：游戏能力（单选等级 + 多选技巧强项/短板）

### 2.1 映射来源

| 优先级 | 数据源 | 字段 | 说明 |
|---|---|---|---|
| P0 | `framework.ability` | `level` | Segment级的综合等级 |
| P1 | `experience_capability.capability` | `statement` | Profile层的能力描述 |
| P2 | `experience_capability.experience` | `statement` | 游戏经历（辅助判断） |
| P3 | `framework.ability` | `strengths` / `weaknesses` | Segment级的技巧标注 |

### 2.2 综合等级映射

#### 从前台6档 → 数据源值映射

| 前台标签值 | 产品显示名 | 数据源值 | 判定逻辑 |
|---|---|---|---|
| `novice` | 新手 | `novice` | framework.ability.level 直接映射 |
| `beginner` | 入门 | `beginner` | framework.ability.level 直接映射 |
| `intermediate` | 进阶 | `intermediate` | framework.ability.level 直接映射 |
| `advanced` | 高手 | `advanced` | framework.ability.level 直接映射 |
| `expert_competitive` | 专家/竞技级 | `expert` | framework.ability.level 直接映射 |
| `unknown` | 未知 | `unknown` / 无数据 | 默认值 |

#### 无 framework 标注时的推断规则

当 framework.ability.level 为 `unknown` 或无标注时，从 Profile statement 推断：

| Profile statement 模式 | 推断等级 | confidence |
|---|---|---|
| "高水平""全区前X""顶级""职业""赛事" | `advanced` / `expert_competitive` | 0.75 |
| "技术中等""一般""普通水平""够用" | `intermediate` | 0.70 |
| "自评菜""不厉害""技术不行""新手" | `beginner` / `novice` | 0.75 |
| 仅有时长描述，无能力评价 | `unknown` | — |

> **关键约束**：不能从"玩得久"推断"高手"（Profile规范 §12.5）

### 2.3 技巧标签映射

#### 技巧分类体系（从 Profile statement + framework.ability.strengths/weaknesses 提取）

| 技巧大类 | 前台子标签 | 数据源关键词 |
|---|---|---|
| 枪法 | 拉枪、微调瞄准、压枪、跟枪、预瞄 | "枪法""瞄准""aim""压枪""跟枪""预瞄""headshot""爆头" |
| 身法 | 基础身法、复杂身法、闪身、急停、移动控枪 | "身法""走位""移动""movement""闪身""急停""快速反应" |
| 信息获取 | 听声辨位、复杂场景识敌、信息收集 | "听声""辨位""信息""sound""awareness""地图意识""观察" |
| 战场策略 | 敌情预测、投掷物/技能、路线规划、战撤决策、位置选择、地图记忆 | "策略""战术""路线""决策""投掷物""位置""地图""strategy" |
| 品类知识 | 规则理解、机制理解、角色/武器/版本理解 | "理解""知识""机制""版本""knowledge""meta" |

#### 提取规则

1. **强项**：从 `framework.ability.strengths` 直接提取 + 从 Profile capability statement 中正向描述提取
2. **短板**：从 `framework.ability.weaknesses` 直接提取 + 从 Profile capability statement 中负向描述提取
3. **数量限制**：强项和短板各最多取 confidence 最高的 3 个
4. **无证据时**：不强制填充，前台显示"未知"

4. **区分"当前使用"和"真实偏好"**：若 Profile 中有"因设备限制用手机但偏好PC"等表述，以真实偏好为准

## 6. 冰山心智链（M1→M5）

### 6.1 映射来源

冰山心智链**直接继承 Segment 层的 iceberg 标注**，在 Profile 层聚合展示，不作为前台筛选项。

| M层 | 数据源 | 聚合方式 | 前台展示 |
|---|---|---|---|
| M1 动机 | `iceberg.M1_motivation` | 取所有 Segment 的 confirmed M1，按频次排序 | "为什么玩" |
| M2 期待 | `iceberg.M2_expectation` | 取所有 Segment 的 confirmed M2，按频次排序 | "期待什么" |
| M3 认知 | `iceberg.M3_perception` | 取所有 Segment 的 confirmed M3，按频次排序 | "怎么理解游戏/自己" |
| M4 感受 | `iceberg.M4_feeling` | 取所有 Segment 的 confirmed M4，按频次排序 | "过程中的情绪" |
| M5 行为 | `iceberg.M5_behavior` | 取所有 Segment 的 confirmed M5，按频次排序 | "实际做了什么" |

### 6.2 与 Profile 维度的关系

| M层 | 对应的 Profile 维度 | 关系 |
|---|---|---|
| M1 | `motivations_needs.motivation` | M1 是动机的原子标签，Profile 层 motivation 是聚合后的归纳 |
| M2 | `motivations_needs.expectation` / `need` | M2 是期待的原子标签 |
| M3 | `perceptions_beliefs` | M3 是认知的原子标签 |
| M4 | `perceptions_beliefs.emotion` | M4 是感受的原子标签 |
| M5 | `behaviors` | M5 是行为的原子标签 |

### 6.3 聚合规则

1. 同一 Respondent 的所有 Segment 的 iceberg 标签按 M 层分别聚合
2. 同一标签值出现多次 → 合并，记录频次
3. 不同标签值 → 分列，按频次排序
4. 冰山链作为画像详情展示，不为空
