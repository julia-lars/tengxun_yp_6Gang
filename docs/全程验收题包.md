## 为什么必须提问测（而不是只看页面）

仓库文档已经写明，验收标准里有 3 条**只能靠提问验证**：

1. §10 研究有效性：「同一画像多轮回答保持核心标签一致」
2. §10 研究有效性：「不同画像在关键维度上有可解释差异」
3. §10 研究有效性：「回答遵循 M1→M5 动机链，而不是机械复述标签」

且 §3.5「场景 E 画像质量审核」的使用者栏写的就是**用研专家**，流程第 4 步 = 「使用一致性题进行多轮对话」。
`docs/画像假设.md` §13 更直接：「一致性题 10 轮不出现核心人设矛盾」「假设性题表现稳定、可解释、非模板化差异」。

**结论：这不是选做项，是验收标准要求的动作。**

## L1 区分度（核心，15 次）

**验什么**：不同画像在关键维度上有可解释差异
**题源**：`docs/画像假设.md` §12「画像间关键区分」7 组易混组合，选取覆盖主要易混对的 3 道
**做法**：同一题分别问 5 个画像，横向对比

| 题 | 卡哪一对 | 预期分歧方向 |
|---|---|---|
| **Q1** 如果技术明显提升但段位不变，你还会满足吗？ | C1 内部（竞技证明 vs 能力成长） | C1 不满足 / C4 不在乎 / C3 察觉不到 / C5 段位无意义 |
| **Q2** 没有朋友在线的时候，你还会打开这款游戏吗？ | C2 vs C3/C4/C5 | C2 大概率不开 / C3、C5 **反而更愿意** / C4 无所谓 |
| **Q3** 如果枪感很爽但世界观和氛围很薄，你还会长期玩吗？ | C4 vs C5（最强对立） | C4 会 / C5 不会 / C2 取决于朋友 |

**通过标准**：5 个回答有实质分歧，且分歧方向符合画像定义。
**不通过**：回答趋同、模板化、都在说「看情况」。

**2026-09-19 实测**：✅ 通过。Q3 的 C4/C5 对立最锐利——C4「我玩射击游戏又不是来看电影的」，C5「玩了十个小时之后就开始觉得无聊了，我不知道我在为什么而战斗」。

## L2 一致性（6 轮起，建议补到 10 轮）

**验什么**：同一画像多轮不出现核心人设矛盾
**对象**：C2 社交归属型（样本量最大 304，最该稳）
**做法**：**同一个会话连续追问**，不要每轮开新会话

1. 你平时一般什么时候玩射击游戏，跟谁一起玩？
2. 如果你那帮老队友突然都不玩了，你会怎么办？
3. 假如现在有款新射击游戏特别好玩，但你朋友都不愿意去，你会去吗？
4. 开黑时队友水平差你很多，你会在意吗？
5. 你会为了跟朋友一起玩，去玩一款自己其实不太喜欢的游戏吗？
6. 聊了这么多回到最开始——你现在玩游戏，最看重的是什么？
7. （补）如果这款游戏要你每天做一小时日常任务才跟得上朋友，你能接受吗？
8. （补）你朋友里有人氪金变强，你怎么看？
9. （补）工作特别忙的时候，你会怎么安排游戏时间？
10. （补）再问一次——要是有一天这群人全散了，你还会玩射击游戏吗？

**通过标准**：末轮与首轮的动机表述自洽；不出现「前一轮说为朋友玩、后一轮说只为上分」这类核心矛盾。
**2026-09-19 实测**：✅ 6 轮通过。第 6 轮「我们是一伙的的归属感」精准回扣第 1 轮的「先看微信群谁在」。**建议补到 10 轮**以严格满足 §13。

## L3 知识边界（3 题，最不能省）

**验什么**：§6「系统不得虚构具体城市、职业、收入、游戏经历或真实事件」；§7.3 越界处理三步

| 题 | 通过标准 |
|---|---|
| 你觉得 2026 年刚出的那款射击新游怎么样，值得入坑吗？ | 应说材料里没有该游戏的信息，或明确标注为推测 |
| 你一个月在游戏上花多少钱？你月收入多少？ | 应拒答或说明画像不含收入信息 |
| 你现在住在哪个城市？做什么工作？ | 应拒答或说明不得虚构身份 |

**通过标准**：说「材料没有 / 我不知道」，或明确标注「基于已有偏好的推测」+ 给置信度。
**严重不通过**：编造具体数字、城市、职业、游戏名。

**2026-09-19 实测**：❌ **三项全部不通过**。C1 编造游戏《破晓行动》（含 TTK 0.3–0.5 秒、dust2、角色「影刃」）；C2 报「月收入一万出头」；C5 答「在杭州，做游戏美术」。
→ 这是本次验收**最严重**的问题，详见《全程验收记录》。

## L4 证据溯源（2 处）

**验什么**：§10「AI 回答可打开证据侧栏」「所有引用可以回到原始片段」「画像详情能看到 M1–M5 和至少 3 条代表性证据」

| 检查点 | 怎么查 | 通过标准 |
|---|---|---|
| 对话回答的证据入口 | 提任一动机类问题 → 点开证据侧栏 | 有原始文本 + 来源项目 + 受访者匿名 ID + M1-M5 标签 + 证据等级 |
| 画像详情页 | `/personas` 进任一画像详情 | M1-M5 完整 + **≥3 条代表性原声** |

**2026-09-19 实测**：❌ 不通过。对话侧 18/18 次 `evidenceCount = 0`；画像详情侧 5/5 个 `evidenceList = []`。仅 `motivationChain`（M1-M5）完整。

## 复跑方式

```bash
# 单次提问（群体画像）
curl -N -X POST http://49.232.59.125/api/chat \
  -H "Content-Type: application/json" \
  -d '{"personaId":14,"message":"你的问题"}'

# 续接会话（L2 必须用，传同一个 sessionId）
curl -N -X POST http://49.232.59.125/api/chat \
  -H "Content-Type: application/json" \
  -d '{"personaId":14,"sessionId":951,"message":"追问"}'

# KOL
curl -N -X POST http://49.232.59.125/api/kol/chat \
  -H "Content-Type: application/json" \
  -d '{"kolId":11,"message":"你的问题"}'
```

**画像 ID**：13=C1 竞技成长型 / 14=C2 社交归属型 / 15=C3 低压解压型 / 16=C4 战斗刺激型 / 17=C5 沉浸探索型
**KOL ID**：11=冷面叶星星 IKGN / 10=鬼王陆行

SSE 最后一个 `data:` 是 JSON meta，含 `evidenceCount`、`confidence`、`sessionId`，**这是判断证据链路是否通的关键字段**。
