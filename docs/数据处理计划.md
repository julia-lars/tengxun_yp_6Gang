## 分步操作

### 第 1 步：建立文件索引

先不处理内容，把每个文件的基本信息登记好。

**要记录的信息：**
- 文件名、所属研究项目
- 文件类型（docx / xlsx）
- 语言（中文 / 英文 / 中英混合）
- 访谈形式（座谈会 / 深访 / 线上访谈 / 文字转录）
- 预估内容量（段落数、总字数）

**产出：** `data/file_index.csv` — 每行一个文件的基本信息

**怎么让 Claude 做：**

> 遍历 `虚拟用户-笔录 for 元培/` 下所有 docx 和 xlsx 文件。对每个 docx 用 python-docx 读取段落数和总字数；对每个 xlsx 用 openpyxl 读取 Sheet 名称和行列数。把所有信息整理成一个 CSV 文件，保存到 tengxun_yp_6Gang/data/file_index.csv。

---

### 第 2 步：处理 docx 文件

66 个 docx 文件逐个处理。每个文件的结构不同（有的是 Q&A 对话体，有的是连续叙述），需要分两步：

#### 2a：提取纯文本

- 用 python-docx 提取所有段落
- 保留段落之间的换行
- 去掉页眉页脚、页码等非正文内容

#### 2b：按说话人分片

docx 里的对话格式大致是：

```
Moderator: 你平时玩什么射击游戏？
张三: 主要是 CS 和 Valorant。
Moderator: 为什么喜欢这两款？
张三: 因为枪法要求高，打赢很有成就感。
```

需要把 Moderator（主持人）的提问和被访者的回答区分开，**只保留被访者的发言**。

**产出：** `data/segments/` 目录，每个 docx 对应一个 JSON 文件：

```json
[
  {
    "source": "美国HD端用户生态与决策链路研究/座谈会笔录-G1（放松向）.docx",
    "segment_index": 1,
    "speaker": "Jordan K.",
    "text": "I mostly play Call of Duty, just to relax after work..."
  },
  {
    "source": "...",
    "segment_index": 2,
    "speaker": "Morgan P.",
    "text": "For me it's more about the social aspect..."
  }
]
```

**怎么让 Claude 做：**

> 处理 `虚拟用户-笔录 for 元培/` 下的所有 docx 文件。对每个文件：用 python-docx 提取段落文本，识别 Moderator 和被访者的发言交替模式，只保留被访者的发言，按段落分片。每个文件输出一个 JSON 文件，保存到 tengxun_yp_6Gang/data/segments/。格式：{ source, segment_index, speaker, text }。

---

### 第 3 步：处理 xlsx 文件

2 个 xlsx 文件结构不同，需要分别处理。

**枪战类长线新手体验研究/用户记录表.xlsx：** 11 个 Sheet，重点提取"玩家行为&乐趣整理"、"经验认知乐趣对比"、"特征诉求"这几个 Sheet 里的玩家原话。

**生存撤离类新手引导体验研究/整合记录表.xlsx：** 重点提取含玩家访谈记录的 Sheet。

**产出：** 同样格式的 JSON 文件，和 docx 的产出合并放在 `data/segments/`。

**怎么让 Claude 做：**

> 处理这两个 xlsx 文件。用 openpyxl 读取每个 Sheet，识别包含玩家原话的列，提取出来，按行分片。输出格式和 docx 一样：{ source, segment_index, speaker, text }。保存到 data/segments/。

---

### 第 4 步：数据清洗

文本提取出来后，做一轮基础清洗：

- 去重：如果同一个说话人的前后段落内容高度重复（相似度 > 90%），合并或去重
- 去口语填充词：英文去掉 "um, uh, you know, like, I mean" 等，中文去掉 "那个、就是、怎么说呢" 等（不要太激进，稍微去一下即可）
- 去除纯 Moderator 引导语（如 "Thanks for coming, let's start..."）
- 去除过短的片段（< 20 个字符的无效内容）

**产出：** `data/segments_cleaned/` — 清洗后的版本

**怎么让 Claude 做：**

> 读取 data/segments/ 下的所有 JSON 文件，做数据清洗：去重（相似度 > 90% 的相邻段落合并）、去口语填充词、去 Moderator 纯引导语、去 < 20 字符的无效片段。清洗结果保存到 data/segments_cleaned/。

---

### 第 5 步：合并与统计

把所有清洗后的片段合并成单一文件，做统计分析：

- 总片段数
- 每个研究项目的片段数
- 中英文各多少
- 平均片段长度
- 说话人数量分布

**产出：** `data/all_segments.jsonl` — 一行一个片段，完整的待打标数据集

**怎么让 Claude 做：**

> 把 data/segments_cleaned/ 下所有 JSON 合并成一个 JSONL 文件 data/all_segments.jsonl。然后统计：总片段数、按研究项目的分布、中英文分布、平均片段长度、说话人数量。统计结果保存到 data/segments_stats.md。

## 注意事项

- 搜打撤品类研究/海外有 8 组中英文对照文件（`xxx-中文版.docx` 和 `xxx-英文原版.docx`），处理时优先用中文版，英文原版留作对照
- 漫威争锋的 2 个"文字转录"文件可能格式特殊（不是对话体而是连续叙述），需要单独处理
- 美国 HD 端用户生态研究的 4 个文件已经按用户类型分好了（放松/竞技/社交/叙事），这个标签要保留在 source 字段里
- 输出全部用 UTF-8 编码
