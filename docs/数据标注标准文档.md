## 1. 标注框架总览

### 1.1 双层标注体系

每条访谈片段（`source_segments` 的一行）需要完成两层标注：

```
┌─────────────────────────────────────────────────────┐
│                   标注体系                           │
├─────────────────────────┬───────────────────────────┤
│  冰山五层 (Iceberg)      │  框架七维 (Framework)      │
│  ─────────────────────  │  ─────────────────────    │
│  M1 动机/诉求           │  诉求 (Needs)              │
│  M2 期待/标准           │  能力 (Ability)            │
│  M3 认知/观点           │  风格 (Style)              │
│  M4 感受/情绪           │  平台 (Platform)           │
│  M5 行为/应对           │  模式 (Mode)              │
│                          │  资产 (Assets) ← 扩展      │
│                          │  甜区 (Sweet Spot) ← 扩展  │
└─────────────────────────┴───────────────────────────┘
```

**两层互补关系**：冰山五层是纵向的"为什么→怎么做"因果链，框架七维是横向的"这个人是什么样的"特征画像。同一条片段可能同时触发两层标注，也可能只触发其中一层。

### 1.2 标注粒度原则

| 原则 | 说明 |
|------|------|
| **一碎片一标注** | 每条片段独立标注，不依赖同一说话人的其他片段 |
| **原文为准** | 标注基于片段中**明确表达**的内容，不做推断跳级 |
| **宁缺毋滥** | 无法确定层次/维度时标注为空，不强行归类 |
| **多标签允许** | 一条片段可以在同一层次有多个标签值（如同时涉及"竞技证明"和"能力成长"） |
| **上下文保留** | 标注时需参考 `preceding_question` 字段，理解说话人是在回答什么问题 |

### 1.3 证据等级体系

每条标注必须基于明确的证据等级。证据等级决定置信度上限，防止过度推断。

| 等级 | 定义 | 示例 | 置信度区间 |
|------|------|------|:---:|
| **E3 直接证据** | 玩家直接陈述行为、偏好、感受或理由 | "我就是喜欢跟朋友开黑，输赢无所谓。" | 0.85–1.0 |
| **E2 强推断** | 片段存在明确行为→原因或感受→原因关系 | "朋友都退了以后我也基本没开过游戏。"可推断社交归属 | 0.70–0.85 |
| **E1 弱推断** | 只有单一线索，存在多种合理解释 | "我每天都打排位。"不能单独判断是能力成长还是竞技证明 | 0.50–0.70 |
| **E0 无证据** | 没有相关信息 | 输出 `unknown` | N/A |

**强制约束：**

- M1/M2 若无 E3 证据，最高置信度 ≤ 0.70（即 medium）。
- 人口属性（城市等级、收入、能力等级）不得从语言风格、游戏偏好或语气猜测——违者视为标注错误。
- 每个标签值必须关联至少一条 evidence，包含原文引用和证据等级。
- AI 标注置信度 < 0.6 时，`review_status` 必须设为 `"review"`，进入人工复核队列。

**证据等级与置信度映射：**

| 证据等级 | 置信度区间 | 含义 |
|:---:|:---:|------|
| E3 | 0.85–1.0 | 几乎确定，原文直接表达，无歧义 |
| E3（单一） | 0.80–0.90 | 高置信度，一条直接证据 |
| E2 | 0.70–0.85 | 中等置信度，推断依据充分 |
| E1 | 0.50–0.70 | 低置信度，推断较大但方向合理 |
| E0 | N/A | 不确定，输出 `unknown` |

## 2. 冰山五层标注规范

### 2.1 五层定义

```
      ┌──────────────────────────────────────┐
      │  M1 动机/诉求                         │  ← 最深层：为什么做？
      │  核心驱动力，根本性的心理需求           │
      ├──────────────────────────────────────┤
      │  M2 期待/标准                         │  ← 对游戏"应该是什么样"的期望
      │  对游戏的理想期待、公平标准、设计偏好    │
      ├──────────────────────────────────────┤
      │  M3 认知/观点                         │  ← 对游戏世界的理解和判断
      │  游戏机制理解、评价标准、因果归因        │
      ├──────────────────────────────────────┤
      │  M4 感受/情绪                         │  ← 最表层可观察：感受是什么？
      │  游戏过程中的情绪体验、情感反应          │
      ├──────────────────────────────────────┤
      │  M5 行为/应对                         │  ← 最表层可观察：做什么？
      │  具体行为、游戏习惯、应对策略            │
      └──────────────────────────────────────┘
```

### 2.2 逐层标注指南

#### M1 动机/诉求 — 核心驱动力

**标注时机**：片段中表达了"为什么玩这个游戏/这个模式"的根本原因。

**标签值域**（12 个，与标签选择器一致）：

| 标签 | 英文 key | 识别信号 |
|------|----------|---------|
| 竞技证明 | `competitive_proof` | "想证明自己""段位=能力""比谁强""排名""击败" |
| 能力成长 | `ability_growth` | "想变强""练枪""进步""学习""技术提升" |
| 支配优越 | `dominance` | "碾压""虐菜""统治力""让别人服" |
| 团队协作 | `team_cooperation` | "配合""团队""一起赢""队友""默契" |
| 社交归属 | `social_belonging` | "和朋友玩""社交""聊天""圈子""归属感" |
| 射击爽感 | `stimulation` | "爽""打击感""枪感""爆头快感""手感" |
| 放松逃避 | `relaxation_escape` | "放松""解压""逃避现实""不费脑""休闲" |
| 策略掌控 | `strategy_mastery` | "策略""战术""博弈""算计""智商压制" |
| 探索收集 | `exploration_collection` | "探索""收集""皮肤""成就""全图鉴" |
| 叙事沉浸 | `narrative_immersion` | "剧情""世界观""代入感""角色""故事" |
| 视听审美 | `sensory_aesthetics` | "画面""美术""音乐""皮肤好看""特效" |
| 表达创造 | `expression_creation` | "创造""自定义""DIY""表达自己""独特" |

**标注规则**：
- 每条片段最多标注 3 个动机
- 首个标注的动机自动标记为"首要动机"（`primary: true`）
- 如果片段只表达了情绪/行为，但明显指向某个动机，可标注但 `confidence` 降为 0.6-0.7
- 如果动机是推断出来的（非原文直接表达），标注 `inferred: true`

**标注示例**：

```
原文："我打排位就是为了上分，看到段位涨了特别有成就感，输了就特别不爽"
→ M1: ["竞技证明"]  ← 原文直接表达，"上分""段位""成就感"
   confidence: 0.90

原文："每天下班回家打两把，什么也不想，就放松一下"
→ M1: ["放松逃避"]  ← "什么也不想""放松"
   confidence: 0.85

原文："跟朋友开黑特别有意思，我们能聊一晚上"
→ M1: ["社交归属"]  ← "朋友开黑""聊"
   confidence: 0.80
```

#### M2 期待/标准 — 对游戏的期望

**标注时机**：片段中表达了"游戏应该怎样"或"好游戏的标准是什么"。

**标签值域**（10 个核心标签 + 3 个队友扩展标签）：

**对游戏的期待（核心标签）：**

| 标签 | 英文 key | 识别信号 |
|------|----------|---------|
| 公平竞技 | `fair_competition` | "公平""不能挂""平衡""匹配机制""同水平" |
| 技术决定 | `skill_determines` | "技术决定胜负""不能靠运气""实力说话" |
| 丰富内容 | `rich_content` | "内容多""更新快""新地图""新武器""新英雄" |
| 社交便利 | `social_convenience` | "组队方便""语音""社交系统" |
| 低门槛 | `low_barrier` | "上手简单""新手指引""不肝""不氪" |
| 沉浸体验 | `immersive_experience` | "画面好""音效""氛围""代入感""真实感" |
| 正向社区 | `positive_community` | "社区好""玩家素质""不骂人""友善" |
| 持续挑战 | `continuous_challenge` | "有挑战""不会腻""难度曲线""终局内容" |
| 尊重时间 | `respect_time` | "不应强制在线时长""日常任务不要太肝" |
| 付费公平 | `monetization_fair` | "付费不应影响竞技公平""皮肤可以贵不能加属性" |

**对队友的期待（扩展标签）：**

| 标签 | 英文 key | 识别信号 |
|------|----------|---------|
| 沟通配合 | `teammate_communication` | "队友要沟通""报点""听指挥" |
| 能力匹配 | `teammate_competence` | "队友不能太菜""水平要差不多" |
| 情绪稳定 | `teammate_stability` | "不要动不动就喷人""心态好" |

**标注规则**：
- 每条片段最多标注 2 个 M2 标签
- 期待往往隐含评价（"XX 不好" → 期待的是 XX 的反面）
- 区分 M2 期待和 M3 认知：M2 是"应该怎样"，M3 是"实际是怎样"

**标注示例**：

```
原文："这个游戏的匹配机制太垃圾了，总是排到段位高很多的"
→ M2: ["公平竞技"]  ← 隐含期待：匹配应该公平
   confidence: 0.85

原文："感觉这游戏对新手不太友好，我朋友进来玩了两把就跑了"
→ M2: ["低门槛"]
   confidence: 0.75
```

#### M3 认知/观点 — 对游戏世界的理解

**标注时机**：片段中表达了"XX 是什么/怎么样"的判断、评价、归因。

**标签值域**（两级结构：分类 + 常见标签）：

**对游戏的认知：**

| 分类 | 英文 key | 常见标签示例 |
|------|----------|------|
| 公平性感知 | `fairness_perception` | 匹配机制不公平、外挂泛滥、辅助瞄准过强 |
| 难度感知 | `difficulty_perception` | 上手太难、天花板太高、对新手不友好 |
| 深度感知 | `depth_perception` | 内容太少、很快就腻、策略深度不够 |
| 品质感知 | `quality_perception` | 画面好/差、优化好/差、手感好/差 |
| 商业化感知 | `monetization_perception` | 太氪金、抽奖太坑、不花钱没法玩 |
| 版本环境感知 | `meta_perception` | 版本答案、谁强玩谁、某武器/英雄太强 |

**对自己的认知：**

| 分类 | 英文 key | 常见标签示例 |
|------|----------|------|
| 自我能力定位 | `self_ability` | "我很菜""我是高手""我反应慢了" |
| 自我身份认同 | `self_identity` | "我是竞技玩家""我是休闲玩家" |
| 自我限制认知 | `self_limitation` | "我手速跟不上""练不出来了" |

**对他人的认知：**

| 分类 | 英文 key | 常见标签示例 |
|------|----------|------|
| 对队友 | `teammate_perception` | "队友太坑""路人没法配合" |
| 对对手 | `opponent_perception` | "对面太强""炸鱼的太多" |
| 对厂商 | `developer_perception` | "厂商只想着赚钱""运营不作为" |
| 对社区 | `community_perception` | "社区环境好/差""贴吧都在喷" |

**因果判断：**

| 分类 | 英文 key | 常见标签示例 |
|------|----------|------|
| 因果归因 | `causal_attribution` | "因为外挂泛滥所以退游""因为朋友都在玩所以入坑" |

**标注规则**：
- 每条片段最多标注 2 个 M3 标签
- M3 是五个层次中**最多样化**的，标注时优先从已有分类匹配，无法匹配时用 `category: "other"` 并写明具体内容
- 区分 M3 认知和 M2 期待：M3 是"实际是怎样"，M2 是"应该怎样"
- 区分 M3 认知和 M5 行为：M3 是"怎么看"，M5 是"怎么做"

**标注示例**：

```
原文："我觉得这游戏主要还是看枪法，枪法好走到哪都吃香"
→ M3: ["枪法决定胜负"]
   confidence: 0.90

原文："上了钻石以后发现都是神仙，感觉不是我能打的了"
→ M3: ["天赋上限"]
   confidence: 0.70
```

#### M4 感受/情绪 — 情感体验

**标注时机**：片段中明确表达了情绪状态或情感反应。

**标签值域**（10 个情绪标签 + 情绪维度）：

| 标签 | 英文 key | 识别信号 | 效价 |
|------|----------|---------|:---:|
| 兴奋/激动 | `excitement` | "爽""刺激""激动""肾上腺素" | + |
| 成就感 | `achievement` | "成就感""满足""骄傲""自豪" | + |
| 沉浸/心流 | `flow` | "沉浸""忘记时间""心流""投入" | + |
| 快乐/愉悦 | `joy` | "开心""好玩""快乐""有意思" | + |
| 社交温暖 | `social_warmth` | "感动""温暖""归属感""被认可""朋友" | + |
| 愤怒/挫败 | `anger_frustration` | "气死""烦""砸键盘""想删游戏""挫败" | − |
| 焦虑/紧张 | `anxiety_tension` | "紧张""手心出汗""不敢打""压力" | − |
| 无聊/倦怠 | `boredom_burnout` | "无聊""腻了""没意思""倦怠" | − |
| 失望/失落 | `disappointment` | "失望""没意思了""凉了""退坑""被背叛" | − |
| 麻木/无所谓 | `numbness` | "无所谓""习惯了""麻木" | 0 |

**情绪维度（每个 M4 标注必须包含）：**

- **强度 `intensity`**：`low` | `medium` | `high`
- **触发 `trigger`**：`win_loss`（胜负）| `growth`（成长）| `team`（团队）| `matchmaking`（匹配）| `monetization`（付费）| `cheat`（外挂）| `performance`（性能）| `content`（内容）| `social`（社交）
- **效价 `valence`**：`positive` | `negative` | `neutral`

**标注规则**：
- 每条片段最多标注 2 个情绪（允许混合情绪，如"又爽又气"）
- 情绪标注必须原文有明确的情感词或强烈的情绪语境
- 情绪标签需要标注 `valence`（正/负/中性）

**标注示例**：

```
原文："每次拿到五杀那个感觉，真的太爽了，可以开心一整天"
→ M4: ["兴奋/激动", "成就感"]
   valence: "positive"
   confidence: 0.95

原文："连输五把，气得我直接把游戏关了，真的不想玩了"
→ M4: ["愤怒/挫败", "失望/失落"]
   valence: "negative"
   confidence: 0.90
```

#### M5 行为/应对 — 具体行为模式

**标注时机**：片段中描述了具体的游戏行为、习惯、应对方式。

**标签值域**（14 个标签）：

| 标签 | 英文 key | 识别信号 |
|------|----------|---------|
| 排位/上分 | `ranked_grind` | "排位""上分""冲分""爬段位" |
| 刻意练习 | `deliberate_practice` | "练枪""训练场""练习""练枪房" |
| 看攻略/学习 | `watch_guides` | "看攻略""看视频""学技术""看直播" |
| 社交开黑 | `social_play` | "开黑""组队""双排""五排""和朋友" |
| 休闲匹配 | `casual_play` | "匹配""随便玩""休闲""娱乐模式" |
| 切换模式/产品 | `switch_mode` | "连输两把就去打娱乐模式""换游戏玩" |
| 回流 | `return` | "好久没玩了又回来""重新入坑" |
| 回避陌生人 | `avoid_strangers` | "不打路人局""只跟熟人玩""屏蔽语音" |
| 内容分享 | `content_share` | "发视频""分享战绩""发朋友圈" |
| 消费/氪金 | `spending` | "买皮肤""氪金""充钱""抽奖" |
| 退坑/休息 | `quit_break` | "退坑""删游戏""不玩了""休息一段时间" |
| 换号/炸鱼 | `smurf` | "小号""炸鱼""换号" |
| 追比赛/电竞 | `watch_esports` | "看比赛""追战队""看职业" |
| 社区参与 | `community_engage` | "发帖""贴吧""加群""讨论" |

**标注规则**：
- 每条片段最多标注 3 个行为
- 必须是**具体可观察的行为**，不是态度或倾向
- 行为标签需要标注 `frequency`（如原文有提及）：
  - `daily`：每天
  - `regular`：经常/规律性
  - `occasional`：偶尔
  - `past`：过去做过但现在不做了
  - `planned`：明确计划但尚未执行

**标注示例**：

```
原文："我每天下班先打半小时练枪房，热手了再排位"
→ M5: ["刻意练习", "排位/上分"]
   frequency: "daily"
   confidence: 0.95

原文："以前打排位，现在就看朋友玩，自己偶尔上去打两把匹配"
→ M5: ["休闲匹配"]
   frequency: "occasional"
   confidence: 0.85
```

### 2.3 冰山五层之间的因果链标注

**两阶段因果链策略：**

**阶段一：单片段标注（AI 打标阶段）**

当一条片段中同时出现了多个层次，且明确表达了因果关系时，标注层次间的因果链：

```json
{
  "causal_chain": [
    {"from": "M1", "from_value": "竞技证明", "to": "M5", "to_value": "排位/上分"},
    {"from": "M4", "from_value": "愤怒/挫败", "to": "M5", "to_value": "退坑/休息"}
  ]
}
```

**规则**：
- 因果链只在**同一片段中明确表达了因果关系**时标注
- 不跨片段推断因果链
- 例如："因为想上分（M1），所以每天练枪（M5）" → 标注 M1→M5 因果链

**阶段二：跨片段聚合（画像聚类阶段）**

- 同一用户的所有因果链片段汇总
- 高频因果路径 → 该画像的"典型动机链"
- 矛盾路径保留，标记为 `context_dependent`
- 同时满足：标注阶段严格限定单片段保证可复核性，聚合阶段开放跨片段保证画像深度

## 5. 标注流程与操作规范

### 5.1 标注流程

```
┌──────────┐    ┌──────────┐    ┌──────────┐    ┌──────────┐
│ 1. 阅读   │ → │ 2. M5/M4 │ → │ 3. M3/M2 │ → │ 4. M1    │
│ 完整片段  │    │ 表层标注  │    │ 中层标注  │    │ 深层标注  │
└──────────┘    └──────────┘    └──────────┘    └──────────┘
                                                     ↓
┌──────────┐    ┌──────────┐    ┌──────────┐    ┌──────────┐
│ 8. 质量   │ ← │ 7. 置信度 │ ← │ 6. 因果链 │ ← │ 5. 框架  │
│ 自检      │    │ 打分     │    │ 标注     │    │ 七维标注  │
└──────────┘    └──────────┘    └──────────┘    └──────────┘
```

**为什么从 M5/M4 开始标注**：表层行为（M5）和情绪（M4）是最容易识别的内容，标注准确率最高。从表及里逐步深入，可以减少深层推断的偏差。

### 5.2 标注前置检查

在标注每条片段前，必须确认：

| 检查项 | 说明 |
|------|------|
| 片段长度 | `char_count` < 10 的片段通常为填充词（"嗯""对""好"），标注为空 |
| 说话人角色 | 仅标注 `speaker_role = 'interviewee'` 的片段，主持人/提问者不标注 |
| 前置问题 | 阅读 `preceding_question` 了解语境，避免断章取义 |
| 语言 | 中文片段直接标注，英文/中英混合片段需确保理解正确 |

### 5.3 标注优先级

当片段内容有限时，按以下优先级标注：

```
M5 (行为) > M4 (感受) > M1 (动机) > M3 (认知) > M2 (期待)
```

即：优先标注具体可观察的内容，再标注需要推断的深层内容。

### 5.4 多人标注一致性要求

| 指标 | 主指标（Cohen's Kappa） | 辅指标（百分比一致率） |
|------|:---:|:---:|
| 冰山五层标注 | ≥ 0.75 | ≥ 85% |
| M1/M2（推断难度高） | ≥ 0.65 | — |
| 框架七维标注 | ≥ 0.70 | ≥ 80% |
| 置信度打分 | — | ≥ 90%（差距 ≤0.1） |
| 争议解决方式 | 第三人仲裁，以多数意见为准 | |

**不一致时的处理**：
- Kappa 达标但百分比不达标 → 检查标签分布是否不均，无需调整规则。
- Kappa 不达标 → 必须修订规则，不只看百分比。
- 分歧优先沉淀为边界案例，不只做一次性仲裁。

## 6. 黄金案例标准

### 6.1 黄金案例的定义

黄金案例是用研专家**人工标注的高质量样本**，作为 Few-shot Prompt 的示例。每条黄金案例包含：

```
原文片段 → 完整标注 JSON
```

### 6.2 黄金案例选取标准

| 标准 | 要求 |
|------|------|
| 覆盖度 | 12 种动机各至少 2 条，5 个维度各至少 3 条 |
| 清晰度 | 原文表达明确，不存在歧义，冰山五层均能标注 |
| 复杂度 | 至少 5 条包含多动机、混合情绪、因果链 |
| 长度 | 原文 30-300 字，信息密度适中 |
| 来源 | 来自至少 5 个不同的研究项目，避免单一来源偏差 |
| 数量 | 30 条（当前）→ 目标 50-100 条（持续扩充） |

### 6.3 黄金案例的质量标准

每条黄金案例需要通过**三道检查**：

1. **自检**：标注者自己重读一遍，确认每个标签都有原文支撑
2. **互检**：至少一位其他标注者独立标注，一致率 ≥ 85%
3. **专家仲裁**：不一致的标签由用研专家最终裁定

## 7. 质量管控标准

### 7.1 置信度评分标准

每条标注必须给出置信度（0-1）：

| 置信度 | 含义 | 标注条件 |
|:---:|------|------|
| 0.9-1.0 | 几乎确定 | 原文直接表达，无歧义 |
| 0.8-0.9 | 高置信度 | 原文明确，可能有轻微推断 |
| 0.7-0.8 | 中等置信度 | 需要一定推断，但推断依据充分 |
| 0.6-0.7 | 低置信度 | 推断较大，但方向合理 |
| <0.6 | 不确定 | 标记为 `review_status = "review"`，需人工复核 |

**任何标注的置信度 < 0.6 时，`review_status` 必须设为 `"review"`。**

### 7.2 常见标注错误

| 错误类型 | 错误示例 | 正确做法 |
|------|------|------|
| **层次混淆** | 把"我觉得排位机制很公平"标为 M2（期待） | 这表达的是认知（M3），不是期待（M2） |
| **过度推断** | 原文只说"玩得挺开心"，标注 M1=["竞技证明"] | 没有证据表明开心来自竞技证明 |
| **标签越界** | 用不在值域内的自定义标签 | 优先从已有标签库匹配，新增标签需报备 |
| **忽略语境** | 不看 preceding_question 就标注 | 语境可能完全改变片段的含义 |
| **情绪过标** | 原文"还行吧"，标注 M4=["兴奋/激动"] | "还行"是中性评价，不是兴奋 |
| **频率误标** | 原文只说"我练枪"，标注 frequency="daily" | 除非原文提到频率，否则不标注 frequency |

### 7.3 标注质量指标

| 指标 | 目标值 | 计算方式 |
|------|:---:|------|
| 标注覆盖率 | ≥ 80% | 有至少一个标签的片段数 / 总片段数 |
| 平均置信度 | ≥ 0.75 | 所有标注置信度的均值 |
| 待复核率 | ≤ 10% | review_status="review" 的片段占比 |
| 空标率 | ≤ 20% | 无任何标注的片段占比（含填充词片段） |

### 7.4 质量抽检制度

| 阶段 | 抽检比例 | 合格标准 |
|------|:---:|------|
| AI 打标初期（前 100 条） | 100% | 人工全检 |
| AI 打标稳定期 | 10% | 一致率 ≥ 85% |
| 增量数据 | 20% | 一致率 ≥ 85%，防止标注漂移 |
| 上线前终检 | 5% | 一致率 ≥ 90% |

## 8. 边界情况处理

### 8.1 不可标注的片段

以下类型的片段**不标注**（`annotation` 为空或仅标注 `review_status: "skip"`）：

| 类型 | 示例 | 处理方式 |
|------|------|---------|
| 填充词/口语 | "嗯""对""然后""就是" | char_count < 10 自动跳过 |
| 主持人提问 | "你平时玩什么模式？" | speaker_role 过滤 |
| 纯事实陈述（无态度） | "我玩了一年多了" | 不标注（无冰山/框架信息） |
| 指代不明 | "那个东西挺有意思的" | preceding_question 也无法消歧时跳过 |
| 非游戏内容 | "我是在北京读大学的" | 标注客观属性（城市等级、生活阶段），但不标冰山/框架 |
| 重复转录/同义副本 | 中英文访谈各存一份原文 | 标注时选中文版，英文版标记 `duplicate_of` |

### 8.2 模糊片段的处理

| 情况 | 处理方式 |
|------|---------|
| 动机不明确但情绪强烈 | 标注 M4，M1 留空，不强行推断 |
| 描述他人而非自己 | 不标注为自己的标签，可标注 `refers_to: "others"` |
| 前后矛盾 | 以后出现的为准（说话人可能自我修正），confidence 降低 |
| 假设性表述 | "如果是我，我会..." 视为本人的倾向，正常标注但 confidence 降 0.1 |
| 反讽/夸张 | 标注字面含义，标记 `tone: "irony/hyperbole"`，confidence 降 0.2 |

### 8.3 多语言片段

| 情况 | 处理方式 |
|------|---------|
| 纯中文 | 正常标注 |
| 纯英文 | 正常标注，标签值用英文 key |
| 中英混合 | 正常标注，以中文为主，英文为补充 |
| 游戏术语/缩写 | 理解后标注，如 "TTK" = 击杀时间，涉及"枪法"或"射击爽感" |

### 8.4 跨片段一致性问题

同一说话人的不同片段在标注时：
- **不强制要求**标签完全一致（同一个人在不同语境下可能表达不同侧面）。
- 但如果出现明显矛盾（如片段 A 说"我很菜"，片段 B 说"我是高手"），需要按以下四步处理：

**矛盾处理四步流程：**

1. 检查是否为不同时间、不同产品、不同模式导致。
2. 能解释 → 标注 `context_dependent`，记录条件。
3. 无法解释 → 标注 `conflict`，保留双方证据。
4. **严禁 AI 静默选择其中一条证据丢弃另一条。**

在 annotation 中标记：
```
note: "与片段 X 矛盾，context: 不同产品/不同时期/原因不明"
```
