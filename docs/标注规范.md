# 射击品类用户语料标注规范

> 版本：v2.0  
> 日期：2026-08-13  
> 标注对象：访谈中的单个玩家有效语义片段  
> 目标：为 AI 批量打标、画像聚类、证据检索和模拟用户对话提供统一标准

## 1. 标注目标

标注不是把每句话“塞满标签”，而是忠实记录：

1. 玩家明确说了什么。
2. 可以在什么证据强度下推断什么。
3. 哪些信息未知、矛盾或受场景限制。
4. 该片段如何进入 M1→M5 的心智链。

最终标签必须同时满足：

- **可追溯**：每个结论能回到原始文件、片段和证据文本。
- **可复核**：不同标注者可以依据同一规则得到相近结果。
- **可计算**：字段和值域稳定，能用于聚类、筛选和评测。
- **不过度推断**：没有证据时输出 `unknown`，不凭常识补齐人设。

## 2. 标注单元

### 2.1 基本单元

基本单元为“一名玩家在同一问题语境下表达一个相对完整意思的片段”。

- 同一段包含多个独立观点时，应拆分。
- 必须依赖主持人问题才能理解时，应保留最短必要问题上下文。
- 相邻短句共同构成因果链时可合并。
- 不把不同玩家的发言合并。
- 中英文对照材料优先标中文版，英文原文作为复核证据，不重复计入聚类。

### 2.2 不标注的内容

- 主持人的纯引导、确认、寒暄。
- 无法识别说话人的多人混合陈述。
- 只有“嗯”“对”“不知道”等、离开上下文没有意义的片段。
- 纯产品事实、没有玩家态度或行为的信息。
- 重复转录或中英文同义副本。

## 3. 标注流程

1. 阅读当前片段及前后至少一轮对话。
2. 判断是否为有效玩家证据。
3. 提取客观事实和直接表达。
4. 标注 M5、M4、M3。
5. 仅在因果证据充分时推断 M2、M1。
6. 标注枪战框架四维度及扩展标签。
7. 记录证据跨度、置信度和推断理由。
8. 检查同一用户历史片段是否冲突。

## 4. 证据与置信度

### 4.1 证据等级

| 等级 | 定义 | 示例 |
|---|---|---|
| E3 直接证据 | 玩家直接陈述行为、偏好、感受或理由 | “我就是喜欢跟朋友开黑，输赢无所谓。” |
| E2 强推断 | 片段存在明确行为—原因或感受—原因关系 | “朋友都退了以后我也基本没开过游戏。”可推断社交归属 |
| E1 弱推断 | 只有单一线索，存在多种解释 | “我每天都打排位。”不能单独判断是能力成长还是社交 |
| E0 无证据 | 没有相关信息 | 输出 `unknown` |

### 4.2 置信度

- `high`：E3，或两条以上独立 E2 证据一致。
- `medium`：一条清晰 E2，或多条方向一致的 E1。
- `low`：只有 E1；不得进入自动画像核心标签。
- `unknown`：E0。

关键规则：

- AI 标注置信度 `<0.6` 必须进入人工复核队列。
- M1、M2 若无因果证据，最高只能为 `medium`。
- 人口属性、收入、城市、能力等级不得从语言风格或游戏偏好猜测。

## 5. 冰山五层标注

## 5.1 M5 行为/应对

### 定义

已经发生或明确计划发生的外显行为，以及面对压力时采取的行动。

### 值域（12 个标签）

| 标签 | 英文 key | 识别信号 |
|------|----------|---------|
| 排位/上分 | `ranked_grind` | “排位””上分””冲分””爬段位” |
| 休闲匹配 | `casual_play` | “匹配””随便玩””休闲””娱乐模式” |
| 切换模式/产品 | `switch_mode` | “连输两把就去打娱乐模式””换游戏玩” |
| 回流 | `return` | “好久没玩了又回来””重新入坑” |
| 刻意练习 | `deliberate_practice` | “练枪””训练场””练习””练枪房” |
| 看攻略/学习 | `watch_guides` | “看攻略””看视频””学技术””看直播” |
| 社交开黑 | `social_play` | “开黑””组队””双排””五排””和朋友” |
| 回避陌生人 | `avoid_strangers` | “不打路人局””只跟熟人玩””屏蔽语音” |
| 内容分享 | `content_share` | “发视频””分享战绩””发朋友圈” |
| 消费/氪金 | `spending` | “买皮肤””氪金””充钱””抽奖” |
| 退坑/休息 | `quit_break` | “退坑””删游戏””不玩了””休息一段时间” |
| 换号/炸鱼 | `smurf` | “小号””炸鱼””换号” |
| 追比赛/电竞 | `watch_esports` | “看比赛””追战队””看职业” |
| 社区参与 | `community_engage` | “发帖””贴吧””加群””讨论” |

### 频率标注（如原文有提及）

- `daily`：每天
- `regular`：经常/规律性
- `occasional`：偶尔
- `past`：过去做过但现在不做了
- `planned`：明确计划但尚未执行

### 正例

“连输两把我就去打娱乐模式。”  
标注：`M5.switch_mode`，E3，高置信。

### 反例

“连输肯定很难受。”  
只能标 M4 负向感受，不能标注”换模式”行为。

### 边界

- “我会去练枪”是明确行为意向，可标 M5，但注明 `frequency = planned`。
- “高手都会练枪”是对他人的观点，属于 M3，不属于本人 M5。
- “以前每天玩，现在一周一次”同时标 `past` 和当前状态，不覆盖旧状态。
- 每条片段最多标注 3 个行为。

## 5.2 M4 感受

### 定义

玩家在具体游戏情境中的即时或持续情绪体验。

### 值域（10 个情绪标签 + 情绪维度）

| 标签 | 英文 key | 识别信号 | 效价 |
|------|----------|---------|:---:|
| 兴奋/激动 | `excitement` | “爽””刺激””激动””肾上腺素” | + |
| 成就感 | `achievement` | “成就感””满足””骄傲””自豪” | + |
| 沉浸/心流 | `flow` | “沉浸””忘记时间””心流””投入” | + |
| 快乐/愉悦 | `joy` | “开心””好玩””快乐””有意思” | + |
| 社交温暖 | `social_warmth` | “感动””温暖””归属感””被认可””朋友” | + |
| 愤怒/挫败 | `anger_frustration` | “气死””烦””砸键盘””想删游戏””挫败” | − |
| 焦虑/紧张 | `anxiety_tension` | “紧张””手心出汗””不敢打””压力” | − |
| 无聊/倦怠 | `boredom_burnout` | “无聊””腻了””没意思””倦怠” | − |
| 失望/失落 | `disappointment` | “失望””没意思了””凉了””退坑””被背叛” | − |
| 麻木/无所谓 | `numbness` | “无所谓””习惯了””麻木” | 0 |

### 情绪维度（每个 M4 标注必须包含）

- **强度 `intensity`**：`low` | `medium` | `high`
- **触发 `trigger`**：`win_loss`（胜负）| `growth`（成长）| `team`（团队）| `matchmaking`（匹配）| `monetization`（付费）| `cheat`（外挂）| `performance`（性能）| `content`（内容）| `social`（社交）
- **效价 `valence`**：`positive` | `negative` | `neutral`

### 正例

“最后一枪翻盘特别爽，感觉自己练的东西有用了。”  
标注：`excitement` + `achievement`，强度 `high`，触发 `win_loss` + `growth`，效价 `positive`。

### 反例

“这个模式节奏很快。”  
这是产品认知 M3；除非玩家说明”所以很刺激/很累”，否则不标 M4。

### 边界

- 每条片段最多标注 2 个情绪（允许混合情绪，如”又爽又气”）。
- 情绪标注必须原文有明确的情感词或强烈的情绪语境。
- “累”需要区分身体/注意力疲劳（精力资产）和情绪厌倦（M4）。
- “我觉得不公平”通常是 M3 评价；若同时有”很生气”，再标 M4。

## 5.3 M3 认知/观点

### 定义

玩家如何解释游戏、自己、他人和因果关系。

### 值域（两级结构：分类 + 常见标签）

**对游戏的认知：**

| 分类 | 英文 key | 常见标签示例 |
|---|---|---|
| 公平性感知 | `fairness_perception` | 匹配机制不公平、外挂泛滥、辅助瞄准过强 |
| 难度感知 | `difficulty_perception` | 上手太难、天花板太高、对新手不友好 |
| 深度感知 | `depth_perception` | 内容太少、很快就腻、策略深度不够 |
| 品质感知 | `quality_perception` | 画面好/差、优化好/差、手感好/差 |
| 商业化感知 | `monetization_perception` | 太氪金、抽奖太坑、不花钱没法玩 |
| 版本环境感知 | `meta_perception` | 版本答案、谁强玩谁、某武器/英雄太强 |

**对自己的认知：**

| 分类 | 英文 key | 常见标签示例 |
|---|---|---|
| 自我能力定位 | `self_ability` | “我很菜””我是高手””我反应慢了” |
| 自我身份认同 | `self_identity` | “我是竞技玩家””我是休闲玩家” |
| 自我限制认知 | `self_limitation` | “我手速跟不上””练不出来了” |

**对他人的认知：**

| 分类 | 英文 key | 常见标签示例 |
|---|---|---|
| 对队友 | `teammate_perception` | “队友太坑””路人没法配合” |
| 对对手 | `opponent_perception` | “对面太强””炸鱼的太多” |
| 对厂商 | `developer_perception` | “厂商只想着赚钱””运营不作为” |
| 对社区 | `community_perception` | “社区环境好/差””贴吧都在喷” |

**因果判断：**

| 分类 | 英文 key | 常见标签示例 |
|---|---|---|
| 因果归因 | `causal_attribution` | “因为外挂泛滥所以退游””因为朋友都在玩所以入坑” |

### 正例

“手游辅助瞄准太强就不算公平竞技了。”  
标注：`M3.category = fairness_perception`，`M3.value = aim_assist_harms_fairness`，E3。

### 反例

“我不会开辅助瞄准。”  
这是 M5 行为选择；不能自动推断其公平观。

### 边界

- 玩家引用别人观点但明确不认同，只记录玩家自己的立场。
- 反问和讽刺要结合上下文，不能按字面标注。
- 品牌刻板印象可以标注，但必须保留为”玩家观点”，不能写成事实。
- 每条片段最多标注 2 个 M3 标签。
- 区分 M3 认知和 M2 期待：M3 是”实际是怎样”，M2 是”应该怎样”。
- 区分 M3 认知和 M5 行为：M3 是”怎么看”，M5 是”怎么做”。

## 5.4 M2 期待

### 定义

玩家隐含或明确表达的”游戏/队友/自己应该怎样”。

### 值域（10 个核心标签 + 3 个队友扩展标签）

**对游戏的期待（核心标签）：**

| 标签 | 英文 key | 识别信号 |
|---|---|---|
| 公平竞技 | `fair_competition` | “匹配应该公平””不能有挂””平衡” |
| 技术决定 | `skill_determines` | “技术应该决定胜负””不能靠运气””实力说话” |
| 丰富内容 | `rich_content` | “应该有新地图””持续更新””新武器” |
| 低门槛 | `low_barrier` | “应该容易上手””不肝不氪””新手指引” |
| 沉浸体验 | `immersive_experience` | “画面应该到位””音效””氛围””真实感” |
| 持续挑战 | `continuous_challenge` | “难度曲线要合理””不能很快腻””终局内容” |
| 社交便利 | `social_convenience` | “组队要方便””语音””社交系统” |
| 正向社区 | `positive_community` | “玩家素质要好””不能都是喷子””友善” |
| 尊重时间 | `respect_time` | “不应强制在线时长””日常任务不要太肝” |
| 付费公平 | `monetization_fair` | “付费不应影响竞技公平””皮肤可以贵，不能加属性” |

**对队友的期待（扩展标签）：**

| 标签 | 英文 key | 识别信号 |
|---|---|---|
| 沟通配合 | `teammate_communication` | “队友要沟通””报点””听指挥” |
| 能力匹配 | `teammate_competence` | “队友不能太菜””水平要差不多” |
| 情绪稳定 | `teammate_stability` | “不要动不动就喷人””心态好” |

### 正例

“皮肤贵一点没关系，但不能加属性。”  
标注：`M2.monetization_fair`，E3，高置信。

### 反例

“这把付费枪伤害高 10%。”  
只是事实陈述；无态度时不能推断公平期待。

### 边界

- “希望”不一定是 M2；如果只是想要某内容，可能是产品偏好。只有体现规范性”应该/不能/至少”时优先标 M2。
- M2 可以与现实认知相反，例如”我知道厂商要赚钱，但付费不该影响竞技”。
- 每条片段最多标注 2 个 M2 标签。
- 区分 M2 期待和 M3 认知：M2 是”应该怎样”，M3 是”实际是怎样”。

## 5.5 M1 诉求/动机

### 定义

持续驱动选择和行为的深层目标。M1 通常需要跨片段证据，不应从单句随意推断。

### 核心值域

- `ability_growth`：胜任感、掌握技巧、自我成长。
- `competitive_proof`：通过胜利、排名或强者验证自身价值。
- `dominance`：压制、碾压和优越感。
- `team_cooperation`：共同完成挑战。
- `social_belonging`：维持关系、获得群体归属。
- `stimulation`：射击、速度、破坏和紧张刺激。
- `relaxation_escape`：放松、消磨时间、逃离现实压力。
- `strategy_mastery`：理解复杂系统、做出正确决策、获得掌控感。
- `exploration_collection`：发现、收集与完整性。
- `narrative_immersion`：角色、情感和世界沉浸。
- `sensory_aesthetics`：视听与动作审美。
- `expression_creation`：个性表达、创造与分享。

### 正例

“我会专门花半小时练压枪，因为看到命中率一点点上去特别有成就感。”  
M5：刻意练习；M4：成就；M1：能力成长。证据链完整。

### 反例

“我昨天练了半小时压枪。”  
只有 M5。可能因为朋友要求、任务奖励或比赛准备，不能单句判断 M1。

### 边界

- “赢”可能服务于竞技证明、社交合作或活动奖励，必须追问为什么。
- “和朋友玩”可能是社交归属，也可能只是缺少随机队友压力；需要跨片段判断。
- “放松”与“刺激”可以同时存在，记录主次和场景。

## 6. M1–M5 因果链规则

### 合格链条格式

> 因为 M1（深层动机），玩家期待 M2；基于 M3 的解释，在具体情境下产生 M4，并采取 M5。

示例：

> 因为希望通过竞技证明能力（M1），玩家期待匹配和付费机制公平（M2）；他认为数值付费会破坏技术竞争（M3），看到属性武器时感到愤怒和被背叛（M4），因此拒绝付费并考虑退游（M5）。

### 两阶段因果链策略

**阶段一：单片段标注（AI 打标阶段）**

- 仅当同一片段中明确表达了因果时标注 `causal_chain`。
- 例如："因为想上分（M1），所以每天练枪（M5）" → 标注 M1→M5 因果链。
- 不跨片段推断因果链。
- 不要求每个片段都有五层——单片段通常只覆盖 1–3 层。

**阶段二：跨片段聚合（画像聚类阶段）**

- 同一用户的所有因果链片段汇总。
- 高频因果路径 → 该画像的"典型动机链"。
- 矛盾路径保留，标记为 `context_dependent`。
- 同时满足：标注阶段严格限定单片段保证可复核性，聚合阶段开放跨片段保证画像深度。

### 约束

- 反向推断必须标注置信度，不得把行为唯一归因于某动机。
- 不要求每个片段都有五层。
- 完整心智链应在同一用户的多条证据上聚合，而非单条片段强行拼凑。

## 7. 枪战框架（诉求、资产、能力、甜区 + 风格/平台/模式）

## 7.1 枪战游戏诉求

除 M1 核心动机外，同时标记：

### 一般游戏诉求

- 策略思考
- 高难挑战
- 操作精度
- 剧情故事
- 角色吸引
- 高质量视听
- 社交互动
- 竞争超越
- 数值成长
- 收集完成
- 探索发现
- 个性表达
- 破坏自由
- 情感关系
- 沉浸忘我
- 放松解压

### 枪战竞技诉求

- 能力提升
- 支配他人
- 团队合作
- 刺激寻求

### 强度

每项采用：

- `strong_positive`
- `positive`
- `neutral_or_mixed`
- `negative`
- `strong_negative`
- `unknown`

访谈语料不强行换算为量表分数；只有原始量表回答才能保留 1–5 或 1–7 数值。

## 7.2 游戏资产

### 值域

| 资产 | 主要证据 | 分档 |
|---|---|---|
| 时间 | 每天/每周时长、连续时间、单局接受度 | 充足/受限/严重稀缺/未知 |
| 能力 | 上手、对抗困难、学习成本 | 充足/受限/严重稀缺/未知 |
| 精力 | 集中疲劳、长局负担 | 充足/受限/严重稀缺/未知 |
| 情绪 | 连败、团队压力、负面情绪恢复 | 充足/受限/严重稀缺/未知 |
| 金钱 | 价格敏感、预算、付费水平 | 充足/受限/严重稀缺/未知 |

### 边界

- “不愿付费”不等于金钱稀缺，可能是价值观或公平期待。
- “只玩短局”不一定时间稀缺，也可能偏好快节奏。
- “觉得累”需明确是注意力负荷还是对内容厌倦。

## 7.3 游戏能力

### 三级结构

1. 战斗场景：距离（近/中/远）× 复杂度（低/中/高）。
2. 游戏技巧：枪法、身法、信息获取、战场策略、品类知识。
3. 基础认知能力：推理、程序化动作、游戏知识、视觉空间、听觉处理、运动控制、加工速度、反应速度、心理运动速度、短时记忆、长时记忆。

### 综合能力等级

- 新手、入门、进阶、高手、专家/竞技级、未知。

### 判定证据优先级

1. 可核验成绩：段位、赛事、命中率、稳定表现。
2. 具体技巧叙述及自我诊断。
3. 行为证据：训练、复盘、战术沟通。
4. 自我评价。
5. 语气或游戏时长——只能作弱证据。

### 禁止推断

- 玩得久 = 高手。
- PC 玩家 = 能力高。
- 男性 = 枪法强。
- 高付费 = 能力强。
- 喜欢 PVE = 能力弱。

## 7.4 甜区体验

### 定义

玩家通过学习和简单练习快速提升、动机最强、乐趣较高的阶段。

### 标注字段

- `stage`：新手理解/快速提升/稳定精通/平台/流失。
- `skill`：产生提升感的具体技巧。
- `quantity`：可辨识的甜区技巧数量。
- `length`：短/中/长/未知，并记录时间证据。
- `quality`：低/中/高/未知。
- `flow_factors`：目标清晰、反馈即时、技巧挑战平衡、控制感、专注、行动意识融合、忘我、时间感变化、自目的体验。
- `peak_moment`：玩家描述的峰值事件。
- `plateau_or_dropoff`：平台期或流失触发。

### 边界

- “玩得最久”不一定是甜区，必须有成长或高乐趣证据。
- “第一次赢”可以是峰值体验，但不等于持续甜区。
- 纯外部奖励驱动的肝度不能单独视为高质量心流。

## 7.5 游戏风格

### 定义

玩家在游戏中的行为倾向和决策偏好。

### 3 组双极轴 + 2 组扩展轴

| 轴 | 左端 | 中间 | 右端 |
|------|------|------|------|
| 战斗倾向 | `avoidant` 苟活避战 | `balanced` 灵活平衡 | `aggressive` 主动求战/刚枪 |
| 决策方式 | `strategic` 仔细思考/策略 | `situational` 情境切换 | `instinctive` 本能快速反应 |
| 取胜方式 | `team_based` 团队协作取胜 | `balanced` 团队个人平衡 | `individual` 个人能力取胜 |
| 成长方式 | `progression` 数值养成 | `mixed` 混合 | `skill_based` 操作技巧对抗 |
| 社交方式 | `friends_preferred` 熟人开黑 | `either` 均可 | `solo_or_strangers` 陌生人/单人 |

### 标注规则

- 每组轴单选，同轴两端互斥。
- 不同轴之间不互斥（例如”主动刚枪 + 团队协作”是有效组合）。
- 如果原文明确表明按模式变化，标为中间态并记录条件。
- 注意区分”该玩家偏好这种方式”和”该玩家在描述一种现象”。

## 8. 产品评测扩展标签

为覆盖现有 122 道题，增加以下标签族。它们是偏好或决策条件，不直接等同于 M1。

- 客观与场景：城市等级、生活阶段、设备环境、游玩时段。
- 平台与模式：PC/主机/手机，PVP/PVE，具体射击子品类。
- 玩法：视角、TTK、对局时长、复活、地图、角色、武器、载具、难度、辅助瞄准、新手保护。
- 题材美术：现代军事、历史、科幻、废土、恐怖、二次元；写实、风格化、卡通。
- 社交：固定队、熟人、路人、单排、公会、师徒。
- 商业化：付费水平、方式、动机、价格锚点、公平边界。
- 内容营销：渠道、内容类型、KOL 信任、明星/IP、电竞、UGC。
- 生命周期：迁移条件、流失原因、召回条件、版本期待。
- 容忍阈值：匹配等待、外挂、卡顿、强制组队、学习成本。

标注偏好必须区分：

- `liked`：明确喜欢。
- `accepted`：不特别喜欢，但可以接受。
- `neutral`：无明显态度。
- `disliked`：明确不喜欢。
- `rejected`：会因此拒绝下载/退游。
- `not_experienced`：未体验。
- `unknown`：没说。

## 9. 多标签、互斥和矛盾

### 多标签

- 一段话可同时包含多个 M 层和多个研究标签。
- 同一维度允许主次偏好，但必须记录排序或权重。
- 同一用户的画像以跨片段稳定模式为准，不由单条极端表达决定。

### 互斥

- 同一风格轴两端互斥。
- PVE/PVP 五档主结构互斥。
- 综合能力等级单选。
- 同一时点的主平台单选，但允许次平台。

### 矛盾

出现矛盾时：

1. 检查是否为不同时间、不同产品或不同模式。
2. 能解释则标 `context_dependent` 并记录条件。
3. 无法解释则标 `conflict`，保留双方证据。
4. 不允许 AI 静默选择其中一条。

## 10. 正反面综合示例

### 示例 A：能力成长

原话（示意）：

> “我一开始压不住枪，后来每天去训练场练十分钟。现在中距离能跟住人了，那种进步特别爽。”

标注：

- M5：每日训练场练习。
- M4：进步带来的成就/爽感。
- M3：认为练习能改善跟枪。
- M1：能力成长，high。
- 能力技巧：压枪/跟枪，由弱转强。
- 甜区：快速提升期，反馈即时、技巧挑战平衡。

不得额外推断：

- 竞技段位、主平台、付费水平、城市等级。

### 示例 B：社交归属

原话（示意）：

> “我自己不会开这个游戏，朋友喊我才上。大家都不玩以后我也就卸载了。”

标注：

- M5：被邀请才上线；朋友流失后卸载。
- M4：若无直接情绪词则未知。
- M3：游戏价值依赖朋友共同参与。
- M1：社交归属，high。
- 社交结构：熟人开黑。

不得标：

- 团队协作取胜，除非有配合完成挑战的证据。

### 示例 C：公平期待

原话（示意）：

> “皮肤再贵都随便，但属性枪我肯定不玩，竞技游戏就该看技术。”

标注：

- M2：付费不应影响实力；竞技应技术导向。
- M3：属性付费破坏公平。
- M5：遇到属性付费会拒绝/退出（意向）。
- 商业化：外观付费可接受；数值付费拒绝。
- M1：竞技证明或能力成长只能标 medium，需更多证据区分。

## 12. 质量控制

### 人工黄金案例

- 30 条案例覆盖不同玩家类型、国内外、中英文和不同研究项目。
- 至少覆盖每个 M 层 10 次。
- 至少覆盖四类竞技诉求和五类游戏资产。
- 至少覆盖能力五类技巧各 3 次。
- 至少包含 5 条边界/冲突案例和 5 条 `unknown` 正确使用案例。

### 双人一致性

- 两名标注者独立标注至少 30 条。
- **主指标：Cohen’s Kappa**
  - 冰山五层主标签：≥ 0.75
  - M1/M2（推断难度高）：≥ 0.65
  - 框架五维：≥ 0.70
- **辅指标：百分比一致率**（用于快速筛查）
  - 冰山五层：≥ 85%
  - 框架五维：≥ 80%
- Kappa 达标但百分比不达标 → 检查标签分布是否不均，无需调整。
- Kappa 不达标 → 必须修订规则，不只看百分比。
- 分歧优先沉淀为边界案例，不只做一次性仲裁。

### AI 抽检

- 每轮随机抽检 30 条，兼顾高/中/低置信度。
- 核心标签准确率低于 70%：停止批量入库，调整 Prompt 后重跑。
- 单项错误率超过 20%：专项补充定义和 Few-shot。
- 重点错误：过度推断、层级混淆、把产品事实当玩家态度、忽略上下文、双语重复。

## 13. 当前数据风险

1. 题库文档口径为 142 道，当前 Excel 实际为 122 道，需确认版本。
2. 海外访谈存在中英文对照副本，必须去重后再聚类。
3. 部分清洗片段的 `speaker` 为空，画像聚合前必须恢复或建立可靠的受访者 ID。
4. 原始访谈跨项目、跨年份、跨产品，偏好可能随时间变化；标注必须保留产品和时间上下文。
5. 不能把项目文件夹名称（如”竞技向””社交向”）直接作为每条用户语料的真值标签，只能作为抽样层信息。
