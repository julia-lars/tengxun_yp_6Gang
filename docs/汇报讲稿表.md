### 2. 仓库组织（3 min）

```
tengxun_yp_6Gang/
├── apps/
│   ├── api/src/             # 后端（Hono + Drizzle + LLM SDK）
│   │   ├── db/schema.ts     # 7 张表，pgvector 向量支持
│   │   ├── routes/          # API 路由（personas/chat/kol）
│   │   └── lib/llm.ts       # DeepSeek/GLM/MiniMax 统一封装
│   └── web/src/             # 前端（React + Tailwind + shadcn/ui）
│       └── routes/          # 页面（画像/KOL/对话/历史）
├── packages/shared/src/     # 前后端共享 Zod Schema
├── data/                    # 数据产物
│   ├── segments_cleaned/    # 清洗后的访谈片段（68个JSON）
│   ├── sheets_processed/    # xlsx 结构化提取
│   └── kol/                 # KOL 视频转录（70视频, 17万字）
├── docs/                    # 用研产出（标注规范/画像假设/黄金案例）
├── scripts/                 # 数据处理脚本（17个Python）
├── deploy/                  # Docker Compose 生产部署
└── .github/workflows/       # CI/CD 自动构建部署
```

讲的时候强调三个设计原则：
- **类型安全**：Zod（校验）+ Drizzle（ORM）+ TypeScript 全栈，前后端共享 Schema
- **Monorepo**：Bun workspaces + Turborepo 任务编排，一次 `bun install` 全栈就绪
- **AI 辅助开发**：Claude Code 嵌入协作流程，代码生成 → 审查 → 修复循环

### 4. 当前成果 + 演示（5 min）

成果速览（2 min）：

| 群体画像 | KOL 分身 |
|----------|----------|
| 73 份访谈 → 17,132 片段入库 | 2 位 UP 主 × 70 视频转写 |
