# 6Gang 数据流水线 — 修复总结

## 已完成的修复

### 1. `label_all_v3.py` — 标注断点续跑逻辑修复

**问题**：`--resume` 只检查输出文件是否存在，不检查内容完整性。导致中断后不完整的文件被跳过。

**修复**：
- `--resume` 现在加载已有输出文件，检查每个 kept segment 是否有有效 annotation
- 只跳过已完全标注的文件，不完整的文件自动补全缺失部分
- 修复了 batch 索引 bug：原代码 `start_idx + i` 假设 kept segment 连续排列，当有 removed segment 时索引错位
- 新增 `--retry-failed` 参数：可重新标注之前标记为 api_error 的 segment
- API 重试时自动轮换 API Key
- `http_post` 增加 Session 连接失败回退到直接 `requests.post` 的机制

### 2. `run_pipeline.sh` — 流水线调度脚本更新

**修复**：
- 修正为 10 阶段流水线（原 7 阶段）
- `embed_server.py`（API 服务）替换为 `embed_profiles_v2.py`（Profile Embedding 生成）
- 新增 `--skip-label` 参数，可跳过 AI 标注阶段
- 标注阶段默认使用 `--workers 3`（匹配 API Key 数量）
- 阶段顺序：提取 → 清洗 → 标注 → 合并 → Segment Embedding → Profile 生成 → Profile Embedding → 导入 DB → 分类 → 聚类

### 3. `test_pipeline_smoke.py` — 烟雾测试更新

**修复**：`embed_server.py` 替换为 `embed_profiles_v2.py`，阶段描述更新为 10 阶段。

### 4. `import_source_segments.py` — 导入路径修复

**修复**：
- `EMBED_DIR` 从 `data/embed/profiles/` 改为 `data/embed/segments/`（匹配 `embed_segments.py` 输出路径）
- `load_embedding_vectors()` 改为读取单文件格式（与 `embed_segments.py` 输出匹配）

### 5. `classify_respondents.py` — 分类路径修复

**修复**：
- `EMBED_DIR` 从 `data/embed/profiles/` 改为 `data/embed/segments/`
- `classify_respondents()` 改为读取单文件格式
- **策略3 回退匹配修复**：原代码遍历 `EMBED_DIR.iterdir()` 子目录查找 `segment_embeddings.json`，但 `embed_segments.py` 输出单文件而非子目录结构。修复为直接读取 `EMBED_DIR / "segment_embeddings.json"`
