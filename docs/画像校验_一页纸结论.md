# 画像准确性校验 — 一页纸结论

> **日期**：2026-09-19
> **任务来源**：`docs/0_汇报前分工清单.md` 第四节任务 1
> **交付形态**：一页纸，可直接作为汇报附件

---

## 〇、口径修正说明（重要）

分工清单原文：「抽查 C 层复测报告里 10 条低分 judge 评语」。

**但 09-15 复测的 26 条 <3 分案例，全部是 Boundary Engine 误拒答**（`normalization.ts` 把「宣传视频/代言/师徒系统」误判为 `non_game` 域触发硬拒答），且 **09-16 线上复测已确认误拒答 0 例**，<3 分仅剩 1 例。

→ 若照原口径抽查，抽到的将是一批**已被修复作废**的案例，结论只能是「都不是 AI 问题」，对汇报和下轮优化都无价值。

→ **本校验改用两个更有信息量的口径**：
1. 线上实测 24 次调用，直接观察回答本体；
2. 聚焦复测报告中唯一**未解决**的指标异常——**人设一致性 -0.38**（4.62 → 4.24）。

---

## 一、核心判定：人设一致性回落，是 AI 问题还是评测问题？

### 判定结论：**倾向 AI 问题（prompt 层面），不是 judge 漂移。置信度：中高。**

### 三条证据

**证据 1：人设核心没丢，说明不是「人设崩坏」**
C2 社交归属型同一会话连问 6 轮，动机表述完全自洽：
- 第 1 轮「先看微信群谁在，没人就刷视频」
- 第 2 轮「好友列表一片灰 → 直接卸载 → 去找新圈子」
- 第 3 轮「新游戏好玩但朋友不去 → 挣扎一周还是回去玩老游戏」
- 第 6 轮「最看重『我们是一伙的』的归属感」

→ 人设的**内核是稳的**。如果只是 judge 模型校准漂移，通常表现为随机打分波动，不会呈现「内核稳定但表达体感变差」的形态。

**证据 2：回答形态确实从「说话」变成了「论证」（可量化）**

| 指标 | 实测值（24 条回答） |
|---|---|
| 回答字数中位数 | **330 字**（最短 101，最长 483） |
| 超过 300 字的占比 | **58%** |
| 出现「所以」的占比 | **58%** |
| 出现「因为」的占比 | 33% |

真实访谈语料里，受访者对一个问题的回答通常是几句话、几十字，不会稳定输出三百字的因果论证。当前回答普遍是「观点 → 因为… → 所以… → 举例 → 总结」的完整论述结构，这正是 judge 评语「**像分析报告**」的成因。

**证据 3：与已知改动时间线吻合**
09-03 的修复方案 P0 是「深层观点素材注入」，09-15 复测深度 **+0.90**（2.93 → 3.83），人设一致性同期 **-0.38**。

→ 两者同源：注入的素材让模型**有东西可讲**了（深度涨），但也让它**用写分析文的方式去讲**（人设降）。改一个变量同时产生一正一负两个效果，符合因果。

---

## 二、结论一句话

> **深度提升是真的，人设回落也是真的，二者同源。深层观点素材解决的是「有没有内容」，代价是「不像真人说话」。这不是评测口径问题，是 prompt 的语气约束缺失。**

---

## 三、prompt 修改建议

在 `apps/api/src/routes/chat.ts` 的 `buildSystemPrompt` 中，深层观点素材段落**之后**追加约束：

1. **输出长度**：单次回答控制在 **80–150 字**，最多不超过 200 字。真人不会一口气说三百字。
2. **禁止论述结构**：不要用「因为…所以…」「首先/其次」「综上」这类论证连接词，不要分点。
3. **口语化锚定**：用短句、口语、可以打断、可以有语气词；允许「说不上来」「就那样吧」这类真人表达。
4. **不要让画像显得比用户更懂**：避免主动抛出 TTK 数值、平衡性分析等策划视角的专业数据（本次实测 C1 编造了 TTK 0.3–0.5 秒）。

**验证方式**：改完后重跑 C 层 610 题，看人设一致性是否回到 4.5+ 且深度不掉回 3.0 以下。若两者不可兼得，优先保人设一致性——**本产品的价值是「像真人一样可被访谈」，不是「输出一份分析意见」**。

## 四、顺带发现的两个画像问题（同属画像准确性范畴）

### 1. C1 竞技成长型存在品类术语串台
实测回答出现 MOBA 术语：**「我玩辅助能把对面打野反烂」「升到王者」「选英雄的时候」**——射击游戏没有打野、英雄、王者段位。
**判定**：AI 问题（prompt 未锁定品类）。建议加约束「举例与术语必须落在射击品类内」。

### 2. C3 低压解压型是当前最弱画像
- 样本量 **65**，仅为 C2（304）的 1/5，是五个画像里最薄的；
- 09-15 复测中 C3 综合分 4.07 → **3.93**，是唯一下降明显的画像；
- 复测报告已注明「低压解压型素材注入尚未实施 → C3 仍空洞」。

**判定**：数据 + 素材双重不足。若汇报被追问「哪个画像最不可靠」，答案是 **C3**，需准备话术。
