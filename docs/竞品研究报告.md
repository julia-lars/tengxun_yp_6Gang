# 竞品研究报告 — AI 模拟用户系统

> 撰写：项目组 · 2026-07-30

## 调研范围

聚焦三类竞品：AI 模拟用户调研平台、AI 角色扮演产品、传统用研方法。

---

## 一、Synthetic Users

**网址**：https://syntheticusers.com

**定位**：AI 模拟用户调研平台，帮助企业无需招募真实用户即可完成产品验证。

**核心功能**：
- 创建"合成用户"：设定人口属性、行为特征、心理画像
- 批量调研：发送问卷/访谈提纲，AI 模拟用户批量回答
- 分析报告：自动汇总洞察、情感分析、主题聚类

**产品形态**：SaaS 订阅制，按调研次数收费

**与我们对比**：

| | Synthetic Users | 我们 |
|---|---|---|
| 用户画像来源 | 通用人口模板 + 用户自定义 | 73 份真实射击玩家访谈 → AI 聚类 |
| 领域深度 | 通用（消费品/SaaS/游戏均可） | 射击品类垂直深耕 |
| 对话质量 | 通用 LLM 生成，无真实语料背书 | 有原始访谈片段做 RAG 证据支撑 |
| 证据溯源 | 无 | 每条回答可追溯到具体被访者原话 |
| 目标用户 | 产品经理/创业者 | 游戏用研经理/策划 |
| 标签体系 | 通用人口标签 | 冰山五层 + 枪战框架四维度专业标签 |

**关键差异**：我们有真实语料 + 领域标签体系 + 证据溯源，他们是通用模板 + 无溯源。

## 二、Character.AI

**网址**：https://character.ai

**定位**：AI 角色扮演平台，用户创建/对话虚拟角色。

**核心功能**：
- 创建角色：设定人设描述、示例对话
- 多角色对话：同时与多个角色聊天
- 社区共享：用户可分享自己创建的角色

**产品形态**：免费 + 订阅制

**与我们对比**：

| | Character.AI | 我们 |
|---|---|---|
| 角色来源 | 用户手写 Prompt | 真实访谈数据 → 聚类画像 |
| 对话目的 | 娱乐/陪伴 | 用研访谈/立项咨询 |
| 领域专业性 | 通用角色扮演 | 射击品类专业知识 |
| 证据溯源 | 无 | 可追溯到原始访谈片段 |
| 标签筛选 | 无 | 五维度专业标签选择器 |
| 评测体系 | 无系统评测 | 142 道专业测试题 + 一致性/假设性/盲测 |

**关键差异**：他们是娱乐向角色扮演，我们是专业用研工具。画像质量靠真实数据驱动而非 Prompt 工程。

## 三、传统用研方法（基准对比）

| | 传统深访 | 传统问卷 | 我们 |
|---|---|---|---|
| 单次成本 | 500-2000 元/人 | 5-50 元/份 | 接近零边际成本 |
| 周期 | 2-4 周 | 1-2 周 | 实时对话 |
| 样本量 | 8-15 人 | 200-1000+ 人 | 不限，AI 模拟 |
| 深度 | 高（1-2 小时深访） | 低（选择题为主） | 中高（多轮对话） |
| 可复现性 | 低（因人因时而异） | 中 | 高（同画像重复对话） |
| 适用场景 | 探索性研究 | 验证性研究 | 前置筛选 + 访谈预演 |

**我们的定位**：不是替代传统用研，而是**在用研流程中增加 AI 预筛环节**——用研人员先跟 AI 画像对话测试提纲，淘汰模糊问题，再到真人那里做验证。

---

## 四、差异化定位总结

1. **垂直深耕**：不做通用用户调研平台，聚焦射击游戏品类
2. **真实数据驱动**：画像来自真实访谈语料，不是 Prompt 编造
3. **证据可溯源**：每句 AI 回答都能定位到原始访谈片段
4. **用研工作流嵌入**：标签选择 → 画像匹配 → 虚拟深访 → 证据溯源，完整覆盖用研场景
5. **专业评测**：142 道测试题 + 一致性/假设性/盲测三层次评测

---

## 五、风险与不足

- 打标未完成 → 画像聚类依赖种子数据，尚未验证真实聚类效果
- 样本量有限 → 73 份访谈覆盖的玩家类型可能不完整
- 未做 AB 测试 → 尚未与传统用研方法做效果对比
- 缺少 KOL 方向的直接竞品 → B站 UP 主数字孪生暂无对标产品，但市场验证不足
