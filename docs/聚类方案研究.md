# 画像聚类方案研究 —— 多少个聚类 & 如何分聚类

> 版本：v1.1
> 日期：2026-08-13
> 前置文档：`数据标注标准文档.md`（v2.0）、`画像假设.md`（v1.2，5 主画像）、`Embedding规范.md`（v1.0）
> 目的：确定「6110 条已打标片段 → 群体画像」的最优聚类个数与聚类方法，满足三个约束：**实际可用**（能被标签选择器 / AI 人设直接使用）、**类间相似度低**（画像可明确区分）、**可复现**（同一输入得同一画像）。

---

## 0. 结论摘要（TL;DR）

1. **聚类单位是「受访者」（person），不是片段**。片段先按 `speaker_id` 聚合到人，再对人聚类。
2. **目标个数：主画像 5 个**（v1.2 重构后 C1–C5；若 C1 竞技成长型内部双峰稳定可拆回 6），子型另计、不占主画像名额。
3. **主算法：HDBSCAN**（自动选簇、容忍噪声人）；用 **K-Means + 内部指标扫描**先圈定候选 k 区间，再交给 HDBSCAN 定最终簇。
4. **「低相似度」的量化门槛**：平均轮廓系数 ≥ 0.3（目标 0.5）、Davies-Bouldin ≤ 1.2、任意两簇质心余弦相似度 ≤ 0.7、相邻画像至少在 2 个主维度上显著差异。
5. **特征锚点 = 标签选择器的 5 个主维度 + M1 首要动机**，保证聚类结果和产品检索口径一致。

## 1. 聚类个数：确定方法综述

### 1.1 无监督内部指标法（先圈定 k 区间）

| 方法 | 度量对象 | 最优准则 | 优缺点 |
|---|---|---|---|
| 肘部法则（Elbow / WCSS） | 簇内平方和随 k 下降曲线 | 取「拐点」（边际收益骤降处） | 直观；拐点主观，数据平滑时无拐点 |
| 轮廓系数（Silhouette） | 点内聚 vs 最近邻簇分离 | **最大**化平均轮廓 | 直接奖励「低相似度」，最贴合本需求；O(n²) 慢，假设凸簇 |
| Davies-Bouldin (DB) | 簇内离散度 / 簇间质心距 | **最小**化 | 显式度量分离度；对密度不均敏感 |
| Calinski-Harabasz (CH) | 簇间方差 / 簇内方差比 | **最大**化 | 快、稳定；偏好凸且同尺寸的簇 |
| Gap statistic | log(W_k) 对比均匀零分布 | 最小 k 满足 gap(k) ≥ gap(k+1)−s(k+1) | 更原则性；需 Monte Carlo，慢 |

> 文献：Silhouette（Rousseeuw, 1987）、Davies-Bouldin（Davies & Bouldin, 1979）、Calinski-Harabasz / 方差比准则（Caliński & Harabasz, 1974）、Gap statistic（Tibshirani, Walther & Hastie, 2001）。

**对本项目的用法**：先对受访者特征矩阵跑 K-Means，k 从 4 扫到 8，同时画出 silhouette / DB / CH 三条曲线；取「三指标共同支持」的区间作为候选 k。不单独信某一个指标。

### 1.2 自动选簇法（无需预设 k，作为最终仲裁）

- **HDBSCAN**（Campello et al., 2013；McInnes & Healy, 2017）：基于密度，从聚类层次结构里按「簇稳定性（excess of mass）」自动切出扁平簇；`min_cluster_size` 越小 → 簇越多、噪声越多。**天然输出噪声点（label −1）**——对应「不属于任何画像的人/低质片段」，对本项目是特性而非缺陷。
- **GMM + BIC/AIC**：模型法，用信息准则自动权衡簇数与复杂度；适合重叠但高斯形状的簇，解释性弱于 HDBSCAN。

### 1.3 稳定性法（可复现性关卡）

重采样（bootstrap / 80% 子样本）跑多次聚类，用调整兰德指数（ARI）度量两次聚类标签一致性。**稳定性最高的 k 才是「真」簇数**，而不是指标分数最高的 k。这直接服务「可复现」约束。

### 1.4 领域经验锚点

| 来源 | 惯例个数 | 参考价值 |
|---|---|---|
| 市场细分惯例 | 3–8 段 | 超过 8 段难以执行与传播 |
| UX Persona 实践 | 3–5 个（NN/g 建议） | 人脑能记住、团队能对齐 |
| Bartle 玩家类型（1996） | 4 型 | 游戏玩家分类的经典下限 |
| Quantic Foundry 动机模型 | 6 大动机（后细化为 12） | 射击/网游动机聚类的常见量级 |
| 本项目先验（画像假设 v1.2） | **5 主画像 + 10 子型 + 1 横向属性** | 依据重合分析重构，是检验靶子 |

### 1.5 结论：没有「普适最优数」

簇数本质是**聚类输出、不是输入**。通用做法是四道关交叉定：

> **先验（5）→ 指标扫描（4–8 的 silhouette/DB/CH）→ HDBSCAN 实测 → 稳定性 + 业务可用性（§13 转正标准）**。

最终个数取决于数据，v1.2 重构后预期落在 **5 个主画像**（若 C1 内部双峰稳定可拆回 6），与领域惯例（4–8）一致。

## 2. 「相似度较低」如何量化

「低相似度」= **类间分离度高、类内紧凑**。本项目用四层度量：

### 2.1 类内紧凑 + 类间分离指标

| 指标 | 方向 | 阈值建议 | 含义 |
|---|---|---|---|
| 平均轮廓系数 | 越大越好 | **≥ 0.3 可接受，≥ 0.5 良好** | 每点离本簇近、离邻簇远 |
| Davies-Bouldin | 越小越好 | **≤ 1.2** | 簇间质心距相对簇内散度 |
| Calinski-Harabasz | 越大越好 | 无绝对阈值，取扫描峰值 | 簇间方差 / 簇内方差 |

### 2.2 类间相似度直接度量（硬门槛）

聚类完成后，直接算**任意两簇的质心相似度**：

- **向量质心**：若聚类基于 embedding，质心 = 簇内向量均值再归一化，两簇相似度 = 质心余弦（内积）。要求 **max 两两余弦 ≤ 0.7**，超过的合并。
- **标签质心**：若聚类基于结构化标签，两簇相似度 = 主导标签 Jaccard 系数或主维度分布 KL 散度。要求主导 M1/风格不重复。

### 2.3 业务可区分性（画像假设 §13）

每个画像与最相近画像**至少 2 个主维度显著差异**，且能回答画像假设 §12 的「易混区分题」（如「赢了但朋友体验很差，算成功吗」）。这是「低相似度」的最终业务裁判，比纯指标更关键。

### 2.4 噪声与重叠处理

- HDBSCAN 输出 `−1` 的人不进任何画像，单独归「未定型样本」，避免强行塞进邻近簇拉高类内散度。
- 若某人同时匹配 2 个画像（跨场景切换，如 H8），保留多画像关联（`persona_ids integer[]` 已支持），而不是硬拆成矛盾的两簇。

## 3. 本项目聚类方案

### 3.1 聚类单位与特征设计

**单位 = 受访者（`respondents` 表的 speaker_id 聚合）**。理由：画像描述的是「人」，片段只是证据；且标注文档附录 E 明确要求「画像聚合前恢复受访者 ID」。

**特征（从片段 label 聚合到人）**，锚定标签选择器 5 主维度 + M1：

| 特征 | 来源字段 | 类型 | 聚合方式 | 编码 |
|---|---|---|---|---|
| 首要动机 | `framework.needs.p` | 分类(12) | 按置信度 c 加权众数 | one-hot |
| 次动机 | `framework.needs.s` | 多值集合 | 出现率 ≥ 40% 入选 | 多热 |
| 能力等级 | `framework.ability.lvl` | 有序(6) | 加权中位数 | 1–6 序数 |
| 战斗/决策/求胜/成长/社交风格 | `framework.style` ×5 | 各分类(3) | 各维加权众数 | one-hot |
| 平台 | `framework.platform.p` | 分类(6) | 加权众数 | one-hot |
| 模式结构 | `framework.mode.struct` | 分类(6) | 加权众数 | one-hot |
| 资产(时间/能力/精力/情绪/金钱) | `framework.assets` ×5 | 有序(3+未知) | 加权众数 | 序数，未知=缺失 |
| 甜区阶段 | `framework.sweet_spot.stage` | 分类(6) | 加权众数 | one-hot |
| 冰山链 M2–M5 | `iceberg.M2–M5` | 分布 | 各层主标签 + 占比 | 稀疏多热 |

**缺失/unknown 处理**：遵循标注「禁止推断清单」，`unknown` 编码为独立缺失列，不强行填确定值；某维缺失占比 > 50% 的人在聚类时可降权或单独审视，不为此补全。

### 3.2 距离度量

特征含「分类 + 有序 + 少量数值」的混合类型，**主选 Gower 距离**（对混合类型天然适配）；HDBSCAN 支持预计算距离矩阵。备选：全 one-hot 后取余弦距离（需先归一化）。

### 3.3 算法与流程

```
① 片段→人聚合（speaker_id，加权众数/占比）
② 特征编码（Gower / one-hot）
③ K-Means 扫描 k=4..8 → silhouette/DB/CH 三条曲线 → 圈定候选区间
④ HDBSCAN（min_cluster_size 扫描）→ 实际簇数 + 噪声集
⑤ 稳定性：bootstrap 80% × 20 次，ARI 选最稳的 k
⑥ 类间质心相似度 ≤ 0.7 硬门槛，超阈合并
⑦ 对表画像假设 §13：样本量 / 来源数 / 核心标签率 / E3 证据
⑧ 命名 + 落库 personas（含证据、冰山链、子型）
```

### 3.4 关键参数

| 参数 | 建议 | 依据 |
|---|---|---|
| `min_cluster_size` | 扫描 5 / 10 / 15 / 20 / 30 | 对应 §13「≥30 条语料」的下界（每簇人数 ≈ 语料数/人均片段数） |
| `min_samples` | 1–5 | 保守取值，保留小簇再人工复核 |
| 距离度量 | Gower（主）/ cosine（备） | 混合特征 |
| 候选 k 区间 | 4–8 | 覆盖领域惯例 + 先验 5/6 |
| 类间相似度硬门槛 | 质心余弦 ≤ 0.7 | 保证「低相似度」 |
| 最小簇样本 | 每簇 ≥ 5 人 且 ≥ 3 独立来源 | 画像假设 §13 |

### 3.5 输出与验收

每个最终画像产出：一句话描述、主导 M1 + 5 主维度取值、典型冰山链（高频 M1→M5 因果路径）、≥3 条 E3 证据、≥2 条边界反例、与最近画像的区分题。**验收四道关**：指标达标（§2）、稳定性达标（§1.3）、业务可区分（§2.3）、样本量达标（§3.4）。

## 4. 风险与边界

1. **H8「情境切换」可能降级为横向变量**而非独立画像——若它只在部分样本里体现为「跨场景」，按画像假设 §14 判为调节变量。
2. **H7-B「击杀掠夺」黄金证据不足**——聚类若聚不出稳定簇，不强行命名，标记「待补 E3」。
3. **H5/H6 可能存在大量「爽感+氛围」混合型**——若双峰不成立，合并为「体验导向」一簇并注明内部光谱。
4. **speaker 为空 / 中英对照副本**：聚合前必须恢复受访者 ID、去掉英文副本（标注文档附录 E），否则会人为放大簇数。
5. **公平底线不参与聚类**：它作为横向属性在簇内做方差解释，不预先强制成簇（画像假设 §10）。
